# 仕分け基準・ルーティング・返信テンプレ

担当連絡先の最新情報は `docs/brand-contacts.md` を参照（このファイルの担当名はプレースホルダ）。

## 分類表

| セグメント | 主な経路/手がかり | 用件の例 | 優先度 | ルーティング |
| --- | --- | --- | --- | --- |
| 施工店（整備/板金/コーティング/PPF） | `/contact/shops`、種別=施工店 | 導入検討・料金・機能・デモ | 高 | セールス（施工店担当） |
| 保険会社（損保） | `/contact/insurers`、種別=保険 | 案件連携・実証・契約 | 最高 | 事業開発/損保担当 |
| 代理店 | `/contact/agents`、種別=代理店 | 取扱・紹介・コミッション | 高 | パートナー担当 |
| BtoB 発注 | `/for-btob` 経由 | 部品発注・取引 | 中 | 該当事業担当 |
| 採用 | 本文に「採用/求人」 | 応募・カジュアル面談 | 中 | 採用担当 |
| 取材・メディア | 本文に「取材/掲載/プレス」 | インタビュー・資料請求 | 最高 | 広報 |
| サポート（既存ユーザー） | 本文に不具合/操作質問 | 障害・使い方 | 高 | サポート |
| 営業・売り込み | 一方的な提案/広告 | — | 低 | 返信下書きは作らない（人が判断） |
| その他/不明 | 上記以外 | — | 中 | 一般窓口へ要約付きで渡す |

判定に迷う場合は低めの確信度を明記し、人の確認を促す。

## 返信下書きテンプレ（日本語・一次返信）

> いずれも**下書き**。金額・納期・契約条件は書かず、必要なら `<要確認: …>` を残す。

### 施工店向け
```
<お名前> 様

このたびは Ledra へお問い合わせいただきありがとうございます。
ご関心をお寄せいただいた <用件の要約> について、担当の <要確認: 担当者名> よりご案内いたします。

差し支えなければ、現在のお困りごとや店舗規模（拠点数・主な施工内容）を教えていただけますと、
具体的なご提案やデモのご用意がスムーズです。

オンラインデモのご希望があれば、以下より候補日時をお知らせください。
<要確認: 日程調整リンク/候補>

引き続きどうぞよろしくお願いいたします。
Ledra
```

### 保険会社（損保）向け
```
<ご担当者> 様

お問い合わせ誠にありがとうございます。Ledra の <損保連携/実証 の要約> について、
事業開発担当の <要確認: 担当者名> よりあらためてご連絡を差し上げます。

ご検討の背景や想定スコープ（対象案件・期間など）を伺えますと、
適切な体制でご提案できます。オンラインでの説明も承ります。

何卒よろしくお願いいたします。
Ledra
```

### 代理店向け
```
<お名前> 様

お問い合わせありがとうございます。代理店・パートナーとしてのお取り扱いについて、
担当の <要確認: 担当者名> よりご案内いたします。

貴社のご商流や対象エリア・想定顧客を教えていただけますと、
取扱条件のご相談がスムーズです。よろしくお願いいたします。
Ledra
```

### 取材・メディア向け（要約を添えて広報へ）
```
<ご担当者> 様

ご連絡ありがとうございます。取材・掲載のご相談につきまして、広報担当の
<要確認: 担当者名> よりご返信いたします。媒体名・テーマ・締切・希望形式を
お知らせいただけますと幸いです。よろしくお願いいたします。
Ledra
```

### 一般・その他
```
<お名前> 様

お問い合わせありがとうございます。内容を確認のうえ、担当より改めてご連絡いたします。
お急ぎの場合は、ご用件と希望のご連絡方法をお知らせください。
よろしくお願いいたします。
Ledra
```

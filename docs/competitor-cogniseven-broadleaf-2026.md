# 詳細比較 ── コグニセブン / ブロードリーフ × Ledra

> 作成: 2026-06-25
> 目的: 国内の代表的既存システム「コグニセブン（事故車修理費見積）」「ブロードリーフ（整備・鈑金 業務支援）」を詳細に調べ、Ledra との違い・棲み分け・競合関係を明確にする
> 用途: 営業説明・導入提案・ピッチ補足・社内の競合理解
> 関連: `docs/system-comparison-and-usage.md` / `docs/competitive-positioning-map-2026.md`
> 注意: 価格は代理店・プランにより変動。本書の金額は公開情報からの目安で、正確な見積は各社へ要確認。

---

## 0. 結論（先に要点）

- **コグニセブンも、ブロードリーフも、Ledra の「正面の競合」ではない。狙っている仕事が違う。**
- **コグニセブン** = 事故車を直す時の「**修理費の見積もりを作って保険会社に送る**」システム。主役は **損保・アジャスター・鈑金塗装工場**。世界観は「**事故 → 保険金**」。
- **ブロードリーフ** = 整備工場・鈑金工場の「**日々の業務（車検・伝票・請求・顧客車両管理）を回す**」基幹システム。国内アフター市場で**トップシェア（取引1.5万社以上）**。世界観は「**店の業務オペレーション**」。
- **Ledra** = コーティング/PPF/ラッピング等の「**施工した事実を、お客様・保険・中古車市場に向けて"証明書"として残す**」プラットフォーム。世界観は「**施工 → 証明 → 資産価値**」。
- 3者は **対象業種も、中心に置くデータも、主たる利用者も違う**。むしろコグニセブン・ブロードリーフは「同じ鈑金/整備の世界で**互いに連携して共存**」している（後述§5）。Ledra はその隣にある**別の業種（施工・コーティング）**に立っている。

> **重要な補強材料**: コグニセブンは「見積もりと**写真**を保険会社へ送る（コグニフォトベース）」のが標準機能。
> = 現場と保険の世界では、信頼の根拠はすでに **"写真" を送ること**で成立している。「改ざんできない暗号技術」ではない。
> これは `docs/system-comparison-and-usage.md` §0-1 の主張（**信頼の実体は作業前後の写真**）を、業界の事実が裏付けている。

## 1. コグニセブン（cogniSEVEN）

### 1-1. 基本情報

| 項目 | 内容 |
|---|---|
| 提供元 | コグニビジョン株式会社（旧アウダセブン → cogniSEVEN に改称） |
| 種別 | **事故車修理費 見積りシステム**（国産車対応） |
| 位置づけ | 国内の事故車修理費見積りの**パイオニア／事実上の標準**の一つ |
| 主な利用者 | **損害保険会社・共済団体・自動車ディーラー・整備工場・鈑金塗装工場** |
| 提供形態 | パッケージ/レンタル（代理店販売）。クラウドの画像伝送サービスを併設 |
| 価格目安 | 基本契約料＋年間使用料モデル。代理店レンタルで**月額 8,600円〜**（「オールインワン」例）の提供あり ※プランにより変動 |

### 1-2. 何をするか（中核）

- 部品図（パーツの絵）を**クリックするだけで部品を選択** → **工賃が自動計算**される。
- 鈑金（パネル修理）情報が塗装画面に反映され、**塗装範囲を選ぶと塗装工賃も自動計算**。
- 「作業確認」ボタンで、指数の前提に基づき**計上すべき部品・作業を一覧表示** → **入力漏れを防止**。
- 収録データに **株式会社自研センター策定の「指数」（一部車種）** を含む。年 **12回** 最新車両データを更新。
- → つまり「**事故車を直すといくらか**を、業界標準の指数で、誰でも正確に・素早く見積もる**」のが目的。

### 1-3. 保険会社連携（ここが強い）

- **コグニフォトベース**（連動サービス）で、作成した**見積書と画像（写真）をそのまま損保・共済へ伝送**。
- 二重入力が要らず、見積〜保険提出が一気通貫。
- フィールドインストラクターは**損保アジャスター出身**で訪問指導 → 保険実務に密着。

### 1-4. 強み・弱み（Ledra 視点）

| | 内容 |
|---|---|
| 強み | 指数ベースの**見積精度**／**保険会社への伝送が業界標準**／損保実務への密着／導入実績の厚み |
| Ledra と重ならない点 | 対象は**事故車修理**。コーティング/PPF の**施工証明**は対象外。お客様向けのQR証明書・マイページ・中古車流通連携は無い |
| Ledra が学べる点 | **「写真＋標準データを保険会社に送る」体験がすでに現場標準**という事実。Ledra の保険会社ポータルも"写真で納得させる"設計に寄せるべき |

## 2. ブロードリーフ（Broadleaf）

### 2-1. 基本情報

| 項目 | 内容 |
|---|---|
| 提供元 | 株式会社ブロードリーフ（東証上場・証券コード 3673） |
| 種別 | **自動車アフターマーケット向け 業務支援システム**（整備・鈑金・車販・部品商・SS） |
| 市場地位 | 国内アフター市場向けアプリで**トップシェア**。自動車系事業者**取引1.5万社以上** |
| 主力製品 | **Maintenance.c**（整備）／**Repair.c**（鈑金）／**Maintenance.c SS+**（給油所）／スーパー検査員（車検）等 |
| 基盤 | Broadleaf Cloud Platform（クラウド。旧来は「.cシリーズ／エンジン」等のオンプレ資産も） |
| 価格目安 | 料金シミュレーター・問い合わせ見積制（業種・機能の組み合わせで変動） |

### 2-2. 何をするか（中核）

- **Maintenance.c（整備）**: ブラウザ上で**顧客・車両管理／見積・請求／伝票発行／申請書類作成**。オススメ作業・部品の自動表示、メカニック・ピットの稼働状況の見える化。
- **スーパー検査員（車検）**: 自検協の**スマート継続OSSシステムと連携**、保適証データ登録と同時に**OSS申請**。車検業務を効率化。
- **Repair.c（鈑金）**: ブラウザ上で**顧客・車両管理／損傷部位の指定／鈑金・軽鈑金の伝票作成／工程管理**。
- 周辺に **CTI・POS連携・ローン連携・部品商ネットワーク** など。
- → つまり「**整備/鈑金工場の毎日の業務（受付〜車検〜伝票〜請求〜部品発注）を回す基幹システム**」。

### 2-3. 強み・弱み（Ledra 視点）

| | 内容 |
|---|---|
| 強み | **圧倒的シェアと導入実績**／車検・OSS等の**法定業務に強い**／部品商ネットワーク／整備・鈑金・部品の**業界エコシステム** |
| Ledra と重ならない点 | 対象は**一般整備・鈑金**の業務効率化。コーティング/PPF 専業の**施工工程・施工証明**に最適化されていない。**お客様向け証明書・QR・中古車流通・代理店/保険ポータル**は守備範囲外 |
| Ledra が学べる点 | 法定業務（車検/OSS）連携の作法／部品・資材ネットワーク／「業界標準の基幹」になることのネットワーク効果 |

## 3. 3者の決定的な違い（早見表）

| 観点 | コグニセブン | ブロードリーフ | **Ledra** |
|---|---|---|---|
| ひとことで | 事故車の**修理費見積** | 整備/鈑金の**業務支援** | 施工の**証明書発行** |
| 対象業種 | 鈑金塗装・事故車 | 整備・鈑金・車販・部品・SS | **コーティング/PPF/ラッピング/ボディリペア** |
| 中心データ | 見積（指数ベース） | 伝票・顧客車両・車検 | **施工証明書（写真つき）** |
| 主な利用者 | 損保・アジャスター・鈑金工場 | 整備/鈑金工場のスタッフ | 施工店＋**お客様＋保険会社＋代理店** |
| 世界観 | 事故 → 保険金 | 店の業務オペ | **施工 → 証明 → 資産価値** |
| お客様が見る | ほぼ無し（保険会社向け） | ほぼ無し（店内業務） | **QR/URLでいつでも閲覧** |
| 保険連携 | **写真＋見積を伝送（標準）** | 申請書類中心 | 保険会社ポータルで照会 |
| 中古車流通 | 対象外 | 車販はあるが証明連携は別 | **施工証明を流通の付加価値に** |
| 改ざん防止 | 概念なし | 概念なし | 裏側で自動保証（脇役） |
| 提供形態 | パッケージ/レンタル+伝送 | クラウド基幹 | **マルチテナント SaaS（4ロール）** |

## 4. なぜ「正面の競合」ではないのか（3つの軸）

### 軸① 業種が違う ── 事故修理 vs 施工（コーティング/PPF）

- コグニセブン・ブロードリーフが見ているのは「**壊れた車を直す（事故修理・整備）**」世界。
- Ledra が見ているのは「**きれいな車を守る（コーティング・PPF・ラッピング）**」世界。施工は標準工程が定型で、RO（修理指示）中心の見積とは販売文脈が違う。

### 軸② 中心に置くデータが違う ── 見積/伝票 vs 証明書

- コグニ＝**見積**（保険金の根拠）、ブロードリーフ＝**伝票/業務記録**（社内オペ）。どちらも**事業者側・支払い側に向いた内部データ**。
- Ledra＝**証明書**（お客様への納品物＋第三者への信頼の橋渡し）。**外に向いたデータ**。

### 軸③ 利用者の構造が違う ── 2者構造 vs 4ロール

- コグニ/ブロードリーフは基本「**店（事業者）と、保険会社 or 社内**」の世界。
- Ledra は「**施工店・お客様・保険会社・代理店**」の4ロールで、お客様と中古車流通まで含む **B2B2B2C** 構造。これは設計思想からして別物。

## 5. むしろ「共存・連携」の関係（重要）

コグニセブンとブロードリーフは、**同じ鈑金/整備の現場で互いに連携して使われている**。

- コグニセブンは「**整備管理ソフト（エンジン＝ブロードリーフ系等）と連動**」して、顧客・車両・売上を一元管理できると明記。
- つまり「**見積はコグニ、業務はブロードリーフ**」という**役割分担での共存**が業界の実態。互いに置き換え合う関係ではない。

Ledra の立ち位置:
- Ledra は**この鈑金/整備のエコシステムの"外側（コーティング/PPF専業）"**に立つ。だから「コグニ or ブロードリーフを置き換える」話ではなく、**別業種の標準を新たに作る**話。
- 将来コーティング店が事故対応もする場合、**Ledra（施工証明）＋コグニ（事故見積）の連携**という共存シナリオもあり得る（敵対ではない）。

## 6. 営業・ピッチでの言い方（推奨）

相手が「コグニやブロードリーフがあるのでは？」と言ってきた時の答え方。

> 「コグニセブンは**事故車の修理費を保険会社に見積もって送る**ためのもの、ブロードリーフは**整備/鈑金工場の日々の業務を回す**ためのものです。どちらも素晴らしい標準ですが、**コーティングやPPFの"施工した事実をお客様や中古車市場に証明する"領域は守備範囲外**です。Ledra はそこに特化しています。
> しかも、コグニセブンが**写真を保険会社に送るのが標準**になっていることが示すとおり、現場が信頼するのは難しい暗号技術ではなく**作業前後の写真**です。Ledra はその"写真つき証明書"を、お客様・保険会社・中古車市場に向けて残せる唯一の設計です。」

ポイント:
1. 相手の製品を**否定しない**（業界標準として尊重）。
2. **業種と目的が違う**ことを明確化（事故修理/業務 ≠ 施工証明）。
3. **「写真が信頼の根拠」**という現場の事実で、Ledra の方向性を裏打ちする。

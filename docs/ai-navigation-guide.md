# AIナビ・サイドバー ガイド

管理画面のナビゲーションを刷新した。サイドバーの項目過多を解消し、**AIチャットに自由文を打つ**ことで
画面を開いたり特定の情報を探したりできる。本ガイドは、その使い方と背景をまとめる。

対象: 施工店ポータル（`/admin`）。関連実装は `src/components/ui/AssistantChat.tsx` /
`src/lib/ai/navIntent.ts` / `src/app/api/admin/assistant/navigate/route.ts` /
`src/lib/search/entities.ts` / `src/components/ui/Sidebar.tsx`。

---

## 1. AIに聞いて画面を開く

「予約を開いて」「先月の売上」「膜厚測定」のように**やりたいことを言葉で打つ**と、
該当画面へ切り替わる。

- **起動**: どの管理画面からでも `⌘/Ctrl + J`、または各画面トップバーの「**AIに聞く**」ボタン、
  サイドバー上部の入口ボタン。頻繁に使う導線なので全画面から即起動できる。
- **仕組み**: 軽量モデル（プラン別・Starter は Haiku）が自然文を画面カタログに解決する。
  カタログは既存のナビ定義（`NAV_GROUPS`）を単一の出典として再利用。
- **安全性**: モデルが返した遷移先は、サーバ側で既知カタログに実在するか必ず照合してから使う
  （ハルシネーション経路・オープンリダイレクトの防止）。到達先の権限は既存の `AdminRouteGuard` が担保。
- **フォールバック**: AI が使えない／一致しない場合は、名前が近い画面の静的候補を提示してナビを止めない。
- **入力欄**: 大きめで打ちやすく、日本語IMEの変換確定Enterでは誤送信しない。空欄／「使い方」ボタンで
  例文とショートカットの「検索ワード表」を表示。

## 2. 情報を探す（顧客・車両・証明書・請求書）

特定の相手やモノを名前・番号で探して、その詳細画面を直接開ける。

| 打つ例 | 探すもの | 検索キー |
|---|---|---|
| 「田中さんの情報」 | 顧客 | 名前 / かな / メール / 電話 |
| 「ナンバー品川300」 | 車両 | ナンバー表示 |
| 「車体番号 ABC123」 | 車両 | 車体番号（VIN, `vin_code`） |
| 「トヨタ プリウス」 | 車両 | メーカー / 車種 |
| 「証明書 LD-001」 | 証明書 | 公開ID / 顧客名 |
| 「帳票番号 INV-2024」 | 請求書 | 帳票番号 |

- **挙動**: 単一ヒットは詳細へ即遷移、複数ヒットは候補チップで選択。0件やAIの誤判定時は名前が近い
  画面の候補を出して行き止まりを避ける。
- **権限・境界**: 既存の横断検索と同じく **staff 以上**に限定。全クエリにテナントIDフィルタを付与し、
  テナント境界を担保。証明書の詳細は `public_id` で開く。
- **実装**: 横断検索の本体は `searchEntities()`（`src/lib/search/entities.ts`）に集約し、
  既存のグローバル検索API `GET /api/admin/search` と共有（検索SQLの二重管理を解消）。

## 3. サイドバーのスリム化とピン留め

- **常時表示（コア）**: 予約管理 / メッセージ / 顧客管理 / 車両管理 / 帳票管理 / 証明書 /
  スタッフ管理 / 進捗管理 ＋ ダッシュボード / 承認インボックス。
- **すべての機能を表示**: 末尾のトグルで全グループを展開（従来の全機能に退避できる）。
- **ピン留め**: よく使う画面は各項目の📌で固定し、常時表示に追加できる（`localStorage` に永続）。
- 表示の絞り込みは既存の `filterItems()` を通すため、RBAC / プラン / 業種ゲートはそのまま効く
  （権限の無い機能はピンしても描画されない）。

## 4. ログイン後のファーストビュー

施工店ユーザーはログイン後、**ダッシュボード `/admin`** に着地する。
（代理店は `/agent`、本社専用ユーザーは `/admin/hq-overview`。役割別の専用画面は維持。）

## 5. オンボーディングでの案内

初回ツアー（driver.js）に「AIに聞いて画面を開く」「サイドバーはよく使う機能だけに整理」の
2ステップを追加。新機能追加に伴いツアーキーを更新（`ledra_tour_done_v2`）し、既存ユーザーにも
一度だけ再表示する。設定ページ / ヘルプドロワーからいつでも再生できる。

### 補足・今後
- 車体番号(VIN)検索は部分一致。完全一致優先の並べ替えは未実装（インデックス `idx_vehicles_vin` で高速）。
- AIナビは「画面を開く／情報を探す」までで、予約作成などのアクション実行は行わない（別途の設計が必要）。

# HP 運用 計画ドキュメント

Cowork の `monthly-ops` が**提案**として更新する計画ドキュメント群です。
ここにあるのは**人が承認して初めて実装に進む提案**。実装（記事公開・LP 制作・SEO 修正）は承認後に別スキル/別 PR で行います。

> 運用方針: 各ファイルは**追記・改訂**して履歴を残す（過去の判断を破壊しない）。月次の更新は日付セクションで差分が分かるように。

## ファイル一覧

| ファイル | 内容 |
| --- | --- |
| `keyword-strategy.md` | 注力クエリ（取りに行く/守る/捨てる）、検索意図とページの対応 |
| `article-calendar.md` | 次月以降の記事テーマ・対象読者・狙うクエリ・公開週 |
| `cvr-improvement.md` | CV 経路の課題と改善仮説（優先度付き）、計測方法 |
| `lp-candidates.md` | 新規ランディングページの候補と要件定義（実装前の仕様） |

---

## テンプレ: keyword-strategy.md
```markdown
# キーワード戦略（最終更新 YYYY-MM-DD）
## 取りに行く（攻め）
| クエリ群 | 検索意図 | 対応ページ/予定 | 現状順位 | 備考 |
## 守る（既に上位）
| クエリ群 | 対応ページ | 現状順位 | リスク |
## 捨てる/後回し
| クエリ群 | 理由 |
```

## テンプレ: article-calendar.md
```markdown
# 記事計画（最終更新 YYYY-MM-DD）
| 公開週 | コレクション | タイトル案 | 対象読者 | 狙うクエリ | 状態 |
| 2026-Wxx | news/blog/cases | … | 施工店/損保/代理店 | … | 案/下書き/レビュー |
```

## テンプレ: cvr-improvement.md
```markdown
# CVR 改善計画（最終更新 YYYY-MM-DD）
| 優先 | 対象（LP/導線/CTA） | 課題（データ） | 改善仮説 | 計測（GA4/PostHog） | 状態 |
```

```markdown
# 新規 LP 候補（最終更新 YYYY-MM-DD）

- 目的 / KGI・KPI:
- 対象セグメント・検索意図:
- 主要メッセージ（3点）:
- 想定 URL:
- 必要素材（コピー/画像/事例/数値の出典）:
- 競合/参考:
- 実装見積（ざっくり）:
- 承認後の次アクション:
```

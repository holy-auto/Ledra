## 2. 配信タイミング

### 曜日・時間（JST）
- **火・水・木の 10:00〜11:00** が最有力（週初の受信整理が落ち着き、夕刊・翌朝に拾われやすい）。
- 避ける：月曜午前（受信過多）／金曜午後・連休前／月末月初の繁忙／大型決算・著名キーノート等の話題集中日。

### 段階配信（推奨）
```
D-5〜D-3 : 業界紙・保険系メディアへ個別ブリーフィング（任意でエンバーゴ＝解禁日指定）
D-1      : 投資家・パートナーへ事前共有（ファクトシート添付）
D 10:00  : PR TIMES 一斉配信 ＋ 自社 /news 公開（draft解除）
D 同時   : X / LinkedIn / メルマガ
D+1〜2   : 反応分析、二次コンテンツ（ブログ詳説・FAQ追記）着手
D+7      : 反響まとめ、必要なら英語版・事例化へ展開
```

## 3. LP・CTA連動（実装に紐づく）

### 3.1 記事末CTAを「角度B」に最適化
現状 `news/[slug]/page.tsx` の `CTABanner` は汎用（`/resources`・`/contact`）。**このリリースは損保/OEM向けなので導線を変える**。2案：

- **案A（最小・推奨）**: 本文末リンクを `/contact` → **`/poc`** または **`/contact/insurers`** に変更（MDXを直す）。実装ゼロ。
- **案B（恒久）**: `news/[slug]/page.tsx` を改修し、frontmatter `cta:`（title/primary/secondary）で記事ごとにCTABannerを上書き可能にする。今後の全リリースに効く。

> いずれも `CTABanner` は `trackLocation` を受けるので、`trackLocation="news-parts-integrity"` を渡してCV経路を識別する。

### 3.2 UTM設計（配信元の貢献を測る）
着地URLに付与：
```
?utm_source=prtimes|atpress|x|linkedin|mail-insurer|nikkan-jidosha
&utm_medium=referral|social|email
&utm_campaign=parts-integrity-2026q2
```
- 自社 `/news` への内部リンクにはUTMを付けない（自己参照汚染を避ける）。
- 紙・メール経由は短縮URL（例: `ledra.co.jp/pi`）→ UTM付き `/poc` へ301。

### 3.3 回遊導線（記事内・本文に内部リンク）
- 「ブロックチェーンで改ざん検知」→ `/features/blockchain-anchoring`
- 「保険会社の業務に接続」→ `/for-insurers`・`/contact/insurers`
- 「効果を試算」→ `/roi`
- 「PoC相談」→ `/poc`（主CV）

## 4. `/news` の見せ方

- **OGP統一**：現状ニュース記事は汎用OGにフォールバック。記事別ブランドOGに統一（→ `press-2-visual-spec.md` の実装案）。**配信前に必須**（SNS・チャットでの見栄えがCVに直結）。
- **重要リリースの固定**：`NewsTeaser` は `publishedAt` 降順で最新3件。配信日を最新にすればトップ表示。恒久運用なら frontmatter `pinned: true` 対応を追加検討。
- **タグ運用**：`お知らせ` / `機能アップデート`。検索・絞り込みの一貫性のため新タグを増やしすぎない。
- **構造化データ（JSON-LD）**：現状なし。`NewsArticle` / `Organization` を `news/[slug]` に追加するとリッチ表示・SEOに効く（実装提案）。
- **購読導線**：記事末・一覧にメルマガ登録（既存フッター）を明示。

## 5. 計測とダッシュボード

- **既存の計測素地**：CTAに `data-cta-location` / `data-cta-label`、`CTAButton`/`CTABanner` に `trackLocation`。これらを集計すれば記事→CTAの動線が見える。
- **見るべき数値**：記事PV / 平均滞在 / `news-parts-integrity` 経由の `/poc`・`/contact/insurers` 到達数 / 資料DL / 媒体掲載数 / 被リンク / 指名検索。
- **解析ツール**：〔要確認：GA4 / Plausible 等〕。UTMとイベント計測を上記KPIに対応づける。

## 6. 配信後フォロー（営業ハンドオフ）

- 問い合わせは **1営業日以内** に返信（既存パイロットPRの約束と整合）。
- 受け手が損保/OEMの場合、**Q&AキットPART2（想定問答）を営業に共有**してトーンを統一。提携・事件・特許の地雷を踏ませない。
- 反響の大きい論点は **ブログ詳説 or FAQ** に二次展開（SEO資産化）。

## 3. AI業務自動化（スタンダード以上で全解禁／14種）

Ledra は AI が施工店の事務作業を肩代わりします。「人手が足りない」「事務が苦手」という施工店ほど効果が出ます。

| AI機能 | 何をしてくれるか（やさしく） |
|---|---|
| AI証明書下書き | 施工内容を入力すると、証明書の文章を自動で下書きします |
| AI写真Vision検証 | 施工写真を AI が見て、証明書として適切かをチェックします |
| AI品質チェック | 入力もれ・おかしな数値を自動で指摘します（全プラン基本対応） |
| AIフォローアップ／フォローメール | 次回メンテのご案内メールを自動で作成します |
| AI請求書／見積書 起票 | 施工内容から請求書・見積書の下書きを自動作成します |
| AI仕訳科目推定 | 経理の「勘定科目」を AI が提案します |
| AI問い合わせ分類 | お客さまからの問い合わせを自動で仕分けします |
| AIメッセージ→予約抽出 | LINE等のメッセージから予約内容を自動で読み取ります |
| AIレビュー解析 | 口コミの内容（満足／不満）を自動で分析します |
| AI塗膜厚異常検知 | 塗装の厚みの異常値を自動で見つけます |
| AI在庫引落推定 | 使った部材の在庫の減りを自動で推定します |
| AI推奨価格 | 施工メニューのおすすめ価格を提案します |
| AI物件説明文生成 | 中古車の紹介文を自動で作成します |
| AI多言語翻訳 | 証明書・案内を多言語に翻訳します |

> **AI（エーアイ）とは**: コンピューターが文章や画像を「理解して」作業を手伝ってくれる技術です。施工店の担当者は難しい操作を覚える必要はなく、ボタンを押すだけで使えます。

## 7. 代理店向け メモ：プラン提案の考え方

- **まずフリーで登録してもらう**のが最強の入口です（無料・違約金なし・期間無制限）。
- 月の証明書発行が **10件を超えそう → スターター**、**80件を超えそう → スタンダード** が目安です。
- **複数店舗・スタッフ7名以上・AI活用** ならスタンダード。**API連携・大規模** ならプロ。
- 迷ったら **スタンダード（おすすめプラン）**。AI全解禁＋優先サポートで満足度が高いプランです。

> **代理店コミッション**: 紹介した施工店が契約（有料化）すると、紹介報酬（コミッション）が計上されます。料率は代理店契約で個別に定めます（例: 月額の10%）。詳細は代理店契約書および代理店ポータル `/agent/commissions` をご確認ください。

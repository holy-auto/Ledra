# Ledra 販売代理店 営業キット

> 販売代理店（Agent）の営業ご担当者が、施工店・保険会社などの見込み顧客へ Ledra をご提案・ご説明いただくための公式営業資料セットです。
>
> **対象読者**: Ledra パートナー代理店の営業ご担当者
> **想定シーン**: 初回提案・商談・体験会・社内勉強会・申込前の説明
> **方針**: Ledra やクラウド／ブロックチェーンに詳しくない方でも、この資料だけで一通り説明できることを目指しています。各資料に **用語解説** を入れてあります。
> **最終更新**: 2026-06-13

## 営業の進め方（基本の型）

1. **掴み（5分）** — まず資料4「紹介パンフレット」を見せながら、「Ledra は施工の事実をデジタル証明書として残し、改ざんできない形で検証できるようにする SaaS です」と一言で説明します。
2. **課題ヒアリング（10分）** — 「紙の証明書の管理は大変ではないですか？」「保険会社とのやり取りに時間がかかっていませんか？」など、相手の困りごとを引き出します。
3. **料金提示（10分）** — 資料1「料金プラン・機能比較表」で、相手の規模に合うプランを提案します。**まずは無料（フリープラン）から始められる**ことが最大の安心材料です。
4. **契約条件の説明（5分）** — 資料2「利用規約」で、解約はいつでも可能・違約金なしであることを伝えます。
5. **導入後のイメージ（5分）** — 資料3「操作マニュアル」を見せ、「スマホ1台で、現場のスタッフでもすぐ使えます」と安心していただきます。

> **困ったときの原則**: その場で答えられない質問は、無理に答えず「持ち帰って Ledra 運営に確認します」と伝えてください。誤った説明は信頼を損ないます。

## この資料に出てくる Ledra の基本用語（最初に押さえる5語）

| 用語 | やさしい説明 |
|---|---|
| **施工証明書** | 「いつ・誰の車に・どんな施工（コーティング等）をしたか」を残す、デジタルの証明書です。紙の代わりになります。 |
| **改ざん検知（ブロックチェーン・アンカリング）** | 発行した証明書が後から書き換えられていないかを、誰でも確認できる仕組み。証明書の「本物保証」です。 |
| **マルチテナント SaaS** | インターネット経由で使うソフト。各店舗のデータは完全に分離され、他店からは見えません（テナント＝お店ごとの「いれもの」）。 |
| **ポータル** | 利用者の立場ごとに分かれた専用画面。Ledra には施工店・代理店・保険会社・顧客の4つがあります。 |
| **コミッション** | 代理店が施工店を紹介し、契約が成立したときに代理店へ支払われる紹介報酬です。 |

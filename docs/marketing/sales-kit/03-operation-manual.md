# 【資料3】Ledra 操作マニュアル（はじめての方向け）

> 施工店の現場スタッフが、Ledra をはじめて使うときの手引きです。専門用語が分からなくても、**この順番どおりに進めれば1日の業務が回せる**ように作っています。
>
> **対象**: 施工店のスタッフ（PC・スマホが少し使える方なら大丈夫です）
> **必要なもの**: インターネットにつながった PC かタブレット／スマホ、Ledra のログイン情報（メールアドレスとパスワード）

---

## 0. Ledra（レドラ）とは？

Ledra は、**「いつ・誰の車に・どんな施工をしたか」を、デジタルの証明書として残すサービス**です。紙の証明書の代わりになり、お客さまにはスマホで・保険会社にはその場で確認してもらえます。発行した証明書は後から書き換えできない仕組み（改ざん検知）で守られています。

---

## 1. ログイン（画面に入る）

1. ブラウザ（Chrome や Safari）で Ledra のログインページ `/login` を開きます。
2. **メールアドレス**と**パスワード**を入れて「ログイン」を押します。
3. 入れないときは「パスワードを忘れた方」から再設定できます。

> **ポイント**: 終わったら必ず「ログアウト」しましょう（他の人に見られないため）。

---

## 2. 画面の見方（まず7つだけ覚える）

左側のメニューのうち、毎日使うのはこの7つです。

| メニュー | 何をするところ |
|---|---|
| **ダッシュボード** | お店全体のホーム。今日やることが一目で分かります |
| **顧客** | お客さまの登録・確認 |
| **車両** | お車の登録・施工履歴の確認 |
| **予約** | 来店予約の登録・管理 |
| **証明書** | 施工証明書の作成・発行 |
| **請求書** | 請求書の作成・発行 |
| **設定** | お店の情報・スタッフ・プランの管理 |

> まずはこの7つだけで十分です。慣れてきたら AI 機能やレポートも使ってみましょう。

---

## 3. 1日の仕事の流れ（おすすめの順番）

```
①予約を確認  →  ②お客さま・お車を登録  →  ③施工する  →
④証明書をつくる（写真つき）  →  ⑤お客さまに渡す  →  ⑥請求書を出す
```

この順番どおりに進めれば、自然と記録が残ります。

---

## 4. お客さまを登録する

1. 左メニュー →「顧客」→「新規登録」
2. お名前・電話番号・メールアドレスなどを入れて「保存」

> メールアドレスを入れておくと、後で証明書をメールで送れます。

---

## 5. お車を登録する

1. 左メニュー →「車両」→「新規登録」
2. **車検証をカメラで撮ると、AI が自動で読み取り（OCR）** ます。手入力も可能です。
3. 「保存」を押すと、お客さまと車がひもづきます。

> **OCR（オーシーアール）とは**: 写真の文字をコンピューターが自動で読み取る機能。車検証を撮るだけで入力が終わります。

---

## 6. 予約を入れる

1. 左メニュー →「予約」→「新規予約」
2. お客さま・お車・日時・施工メニューを選んで「保存」
3. 当日は予約を「来店」→「作業中」→「完了」と進めるだけで進捗が記録されます。

> 飛び込みのお客さまは「ジョブ（飛び込み受付）」からその場で受け付けられます。

---

## 7. 証明書をつくる（写真つき）★最重要

1. 左メニュー →「証明書」→「新規作成」
2. お車・施工内容（コーティングの種類、保証期間など）を入れます。
   - **AI証明書下書き**（スタンダード以上）を使うと、文章を自動で下書きしてくれます。
3. **施工写真を必ず1枚以上のせます**（施工前・施工後など）。
4. 「発行」を押すと証明書が有効になります。

> **なぜ写真が必要？**: Ledra は「証拠付きの証明書」を発行するサービスです。写真がないと発行できない仕組みになっています。これがお客さま・保険会社からの信頼につながります。
>
> 発行と同時に、証明書は**ブロックチェーンに記録（アンカリング）** され、後から改ざんできない状態になります。

---

## 8. お客さまに証明書を渡す

| 方法 | やり方 | おすすめの相手 |
|---|---|---|
| **メールで送る** | 証明書画面の「メール送信」 | メールアドレスがある方 |
| **QRコードを見せる** | 証明書画面の QR をその場で読んでもらう | 来店中のお客さま |
| **NFCタグを貼る** | 車に貼ったタグにスマホをかざすと開く | 次のオーナーにも履歴を残したいとき |
| **紙で印刷** | 「PDF出力」して印刷 | 紙を希望される方 |

> **NFC（エヌエフシー）タグ**: 車に貼る小さなシール。スマホをかざすと施工履歴がすぐ開きます。

---

## 9. 請求書を出す

1. 左メニュー →「請求書」→「新規作成」
2. 施工内容・金額を入れて「発行」
   - **AI請求書起票**（スタンダード以上）を使うと、施工内容から自動で下書きしてくれます。
3. PDF にして印刷・メール送信ができます。
4. 状態は「下書き → 送付済 → 入金済」で管理できます。

---

## 10. こんなときどうする？（よくある質問）

| 困りごと | 対処 |
|---|---|
| 画面が固まった | あわてず一度ページを再読み込み。データは自動保存されています |
| 写真がアップできない | 写真が大きすぎる場合があります。少し小さくして再試行 |
| 証明書がお客さまに届かない | メールアドレスの打ち間違いがないか確認。QRで見せる方法も案内 |
| パスワードを忘れた | ログイン画面の「パスワードを忘れた方」から再設定 |
| スタッフに使わせたい | 「設定」→「メンバー」から招待（ID共有はしないこと） |
| 「権限がありません」と出た | あなたのアカウントに操作権限がない場合。お店の代表者に相談 |

---

## 11. プランでできることの違い（現場向けの目安）

- **AI機能（下書き・写真チェック・請求書起票など）は スタンダード以上** で使えます。
- フリー／スターターでも、証明書の発行・お客さま管理・保険会社連携は使えます。
- 詳しくは【資料1 料金プラン・機能比較表】を参照してください。

---

## 12. 使う言葉の意味（用語集）

| 言葉 | 意味（やさしく） |
|---|---|
| **ログイン／ログアウト** | 画面に入ること／出ること |
| **ダッシュボード** | お店全体のホーム画面 |
| **証明書** | 「いつ・誰に・どんな施工をしたか」を残すデジタルの紙 |
| **テナント** | あなたのお店のデータの「いれもの」。他店からは見えません |
| **メンバー** | お店の中で Ledra を使うスタッフ |
| **OCR** | 写真の文字を自動で読み取る機能（車検証の読み取り等） |
| **PDF** | 印刷もメール送信もできるファイルの形 |
| **QRコード** | スマホで読むとページがすぐ開く四角い模様 |
| **NFCタグ** | 車に貼り、スマホをかざすと履歴が開くシール |
| **アンカリング（ブロックチェーン記録）** | 証明書を改ざんできない形で記録すること |
| **AI（エーアイ）** | 文章や写真を理解して作業を手伝ってくれる機能 |
| **アップロード／ダウンロード** | Ledra に登録すること／自分の端末に落とすこと |

---

## 困ったら

- まずは **左メニュー → ダッシュボード** に戻ると安心です。
- 画面内の「ヘルプ」や、公開ガイド `/guide` も参照できます。
- それでも分からないときは、お店の代表者か Ledra のサポート窓口へ。
- **無理に押しまくらず、落ち着いて一つずつ。** 大事なデータは自動保存されているので、画面を閉じても消えることはほとんどありません。

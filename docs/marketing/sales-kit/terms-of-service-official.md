# Ledra サービス利用規約

**制定日：2026年4月1日**
**最終改定日：2026年6月13日**

株式会社HOLY（以下「当社」といいます。）は、当社が提供する施工証明プラットフォーム「Ledra」（以下「本サービス」といいます。）の利用に関し、以下のとおり利用規約（以下「本規約」といいます。）を定めます。本サービスをご利用になる前に、本規約を必ずお読みください。

---

## 第1条（定義）

本規約において使用する用語の定義は、次のとおりとします。

1. 「本サービス」とは、当社が「Ledra」の名称で提供する、施工証明書の発行・管理、顧客・車両管理、請求・帳票、予約、保険会社との案件連携、装着部品の真正性記録、AIによる業務支援、ブロックチェーン・アンカリングおよびタイムスタンプによる記録の真正性担保等を含む一連のクラウドサービスならびに関連する一切のサービスをいいます。
2. 「ユーザー」とは、本規約に同意のうえ、当社所定の方法により本サービスの利用登録を行った法人または個人事業主をいいます。
3. 「利用契約」とは、本規約を契約条件として当社とユーザーとの間に成立する、本サービスの利用に関する契約をいいます。
4. 「アカウント」とは、本サービスの利用のためにユーザーに付与される識別情報（ID・パスワード等）および当該ユーザーが管理するテナント領域をいいます。
5. 「利用者」とは、ユーザーが本サービスを利用させる、ユーザーの役員、従業員その他ユーザーの管理下にある個人をいいます。
6. 「エンドカスタマー」とは、ユーザーが本サービスを通じて施工役務等を提供する、ユーザーの顧客をいいます。
7. 「施工証明書」とは、ユーザーが本サービス上で入力した施工に関する情報および写真等に基づき発行される電子的記録をいいます。
8. 「ユーザーデータ」とは、ユーザーまたは利用者が本サービスに入力、登録、送信またはアップロードした一切の情報（エンドカスタマーの個人情報、車両情報、施工情報、画像等を含みます。）をいいます。

## 第5条（本サービスの内容および施工証明書の性質）

1. 本サービスは、ユーザーが入力した情報に基づき施工証明書その他の記録を電子的に生成・管理する機能を提供するものです。
2. 施工証明書に記載される施工の内容、品質、正確性、適法性その他一切の事項は、当該施工証明書を発行したユーザーが入力した情報に依拠します。当社は、施工そのものの品質、内容または正確性について、何ら保証するものではありません。
3. 当社がブロックチェーン・アンカリングおよびタイムスタンプ等により担保するのは、発行された記録が事後に改ざんされていないこと（記録の真正性）を技術的に検証可能とする点に限られ、入力情報の内容の真実性を保証するものではありません。
4. ユーザーは、虚偽または不正確な情報に基づく施工証明書を発行してはならず、施工証明書の内容について自ら一切の責任を負うものとします。

## 第6条（料金および支払い）

1. ユーザーは、本サービスの利用の対価として、当社が別途定める料金表（料金ページに掲載するもの）または当社とユーザーとの間の個別の合意に従い、利用料金を支払うものとします。料金の税の取扱いは、料金表の表示に従います。
2. 利用料金の支払方法は、クレジットカード決済その他当社が指定する方法によるものとします。プロプランその他当社が認める場合には、請求書払いに対応することがあります。
3. 月額プランの利用料金は、毎月の契約更新日に自動的に決済されます。年額プランの利用料金は、契約期間の開始時に一括して請求されます。
4. ユーザーが利用料金の支払いを遅滞した場合、当社は、本サービスの全部または一部の提供を停止し、または利用契約を解除することができます。この場合、ユーザーは、支払期日の翌日から支払済みに至るまで、年14.6％の割合による遅延損害金を当社に支払うものとします。
5. 既に支払われた利用料金は、本規約または法令に別段の定めがある場合を除き、返金しません。
6. 当社は、料金表を変更することがあります。料金の変更は、第21条に定める方法により周知します。

## 第8条（契約期間・更新・解約）

1. 利用契約の契約期間は、利用契約の成立日から、当該ユーザーが選択したプランに応じて定まる期間（月額プランは1か月、年額プランは1年）とします。
2. 契約期間満了の前日までにユーザーまたは当社から解約の意思表示がない場合、利用契約は同一条件で自動的に更新され、以後も同様とします。
3. ユーザーは、当社所定の方法（マイページからの操作を含みます。）により、いつでも利用契約を解約することができます。解約後も、当該契約期間（月額プランは当月末日）まで本サービスをご利用いただけます。
4. 月額プランについて、月の途中で解約した場合でも、日割りによる返金は行いません。年額プランについて、契約期間の途中で解約した場合でも、残存期間に対応する利用料金の返金は行いません。
5. 解約、利用契約の終了または利用登録の抹消後、当社は、当社のデータ保持方針に従いユーザーデータを一定期間保持した後、これを削除することができます。ユーザーは、必要なユーザーデータを利用契約の終了前に自ら出力・保存するものとします。

4. 当社、他のユーザー、エンドカスタマーその他の第三者の知的財産権、肖像権、プライバシー、名誉その他の権利または利益を侵害する行為

6. 当社の設備に過度の負荷を与える行為、不正アクセス、リバースエンジニアリング、逆コンパイル、逆アセンブルその他本サービスの解析を試みる行為

11. その他、当社が不適当と合理的に判断する行為

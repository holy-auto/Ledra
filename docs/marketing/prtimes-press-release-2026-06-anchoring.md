# 自動車の施工写真を「改ざんできない記録」に — 施工証明SaaS「Ledra」、C2PA×ブロックチェーンの3層改ざん検知を提供

**C2PA写真署名・SHA-256コンテンツハッシュ・Polygonブロックチェーンの3層構造により、施工証明書の真正性を、Ledra以外の第三者が独立して検証できます。写真や個人情報はブロックチェーンに載せず、ハッシュ（64文字の文字列）のみを記録します。**

自動車のコーティング・フィルム・ラッピング・板金・整備の施工記録をデジタル証明書として発行・共有するSaaS「Ledra（レドラ）」を運営する株式会社HOLY（本社：東京都港区、代表取締役：堀越 友輔）は、施工写真と施工証明書の真正性を第三者が独立して検証できる「**改ざん検知付き施工証明**」を提供しています。

デジタル化が進むほど、「**その写真は本当に施工当日のものか**」「**発行後に内容が書き換えられていないか**」という問いが重みを増します。Ledra は、C2PA による写真署名、SHA-256 によるコンテンツハッシュ、Polygon ブロックチェーンへのアンカリングという3層構造で、この問いに **Ledra の運営者ですら後から改ざんできない形** で答えます。

## ■ 背景：デジタル証明が増えるほど問われる「本当にそのままか」

施工現場に積み重なる「確かに施工した」という事実は、これまで紙の記録や担当者の記憶に閉じ込められ、第三者が真正性を確かめる手段がありませんでした。デジタル化はこの課題を解く一方で、新たな問いを生みます。

- **デジタルファイルは差し替えられる**：PDFも写真もファイルである以上、後から編集・差し替えが可能です。
- **サーバーを信頼するしかない**：クラウド管理は、運営者がデータを書き換えられる立場にあることを意味します。保険会社や顧客が「本当にそのままか」を確かめる術がありませんでした。
- **監査のたびに人手がかかる**：真正性の目視確認は、大量案件を扱う損害保険の査定ではスケールしません。

施工証明が保険査定・中古車流通・消費者保護の判断材料になるほど、「**改ざんされていないことを、誰でも・機械的に確かめられる**」仕組みが求められます。

## ■ 解決策：3層の改ざん検知構造

Ledra は、写真・コンテンツ・ブロックチェーンの3つをまとめて守ります。

1. **C2PA写真署名（C2PA 1.3）** — 撮影した写真を証明書と紐付け、C2PA（Coalition for Content Provenance and Authenticity）規格でメタデータに署名を埋め込みます。写真ファイルが後から差し替えられると署名検証が失敗します。
2. **SHA-256コンテンツハッシュ（NIST）** — 証明書の全コンテンツ（施工内容・写真・日時・施工者）をまとめてSHA-256でハッシュ化します。1文字でも変われば、ハッシュは完全に別の値になります。
3. **Polygonへのアンカリング（Polygon PoS）** — そのハッシュを Polygon ブロックチェーンのトランザクションとして刻印します。一度書き込まれた記録を過去に遡って書き換えることは、技術的に不可能です。

## ■ 検証フロー：保険会社の査定シナリオ

損害保険の査定担当者が、施工証明書の真正性を確認する流れは次の通りです。

1. **証明書を受領** — 施工店がQRコードまたはURLで証明書を共有。査定担当者は保険会社ポータルまたは公開検証ページからアクセスします。
2. **ハッシュを再計算** — Ledra が、現在のデータベース上の証明書コンテンツから SHA-256 ハッシュをその場で再計算します。
3. **ブロックチェーンへ照会** — アンカリング時に記録したトランザクションを Polygon ネットワークに照会し、ブロック番号・タイムスタンプとともに登録済みハッシュを取得します。
4. **一致判定 → 真正確認** — 現在のハッシュとブロックチェーン上のハッシュが一致すれば「発行時から内容が変更されていない」と判定し、画面に検証バッジを表示します。

## ■ 設計上のこだわり

- **NFTは使用しない** — 証明書をNFT化する設計ではありません。ハッシュのみをチェーンに刻むため、ガスコストを最小化し、実運用に耐えるコストで動作します。暗号資産の売買とは無関係で、導入店舗が暗号資産を保有する必要はありません。
- **写真・個人情報はチェーンに載せない** — ブロックチェーンに書き込むのは SHA-256 ハッシュ（64文字の文字列）のみ。写真・施工内容・顧客情報は一切記録されず、ハッシュから元データを復元することは計算上不可能です。
- **ガス代は当社が負担** — Polygon のネットワーク手数料（1件あたり数円程度）は Ledra が負担し、施工店側に追加コストは発生しません。
- **既存の証明書も順次アンカリング** — バックフィル機能により、導入以前に発行された証明書も非同期キュー経由で順次アンカリングします。大量件数でも処理が滞りません。
- **Ledraがなくなっても検証できる** — Polygon は Ledra が管理するものではないパブリックなブロックチェーンです。Polygonscan などの外部エクスプローラーからも誰でもハッシュの存在を確認でき、仮に Ledra のサービスが終了しても記録は残り続けます。

## ■ 想定される活用シーン

- **損害保険の査定・不正抑止** — 施工実績を機械的に検証でき、写真の差し替えや日付の改変を抑止。査定の自動化・効率化に寄与します。
- **中古車流通・車両パスポート** — 施工履歴の真正性を担保し、車両価値の説明可能性を高めます。
- **消費者の安心** — 顧客はQRコードから、自分の車の施工記録が改ざんされていないことを自分で確認できます。
- **メーカー・ディーラー** — 認定施工や保証条件の確認において、信頼できる一次記録として活用できます。

## ■ 今後の展開（ロードマップ）

Ledra は真正性の保証を段階的に強化していきます。現在提供している C2PA 署名・SHA-256・Polygon アンカリングに加え、今後は以下の拡張を予定しています。

- **デバイス証明**（Play Integrity / App Attest による撮影端末の正当性検証）
- **ディープフェイク・合成画像の検知**
- **証明書の Merkle バッチアンカリング**による大量発行時の効率化
- 上記を反映した**段階的な真正性グレード**（標準 → 検証済み → プレミアム）の提供

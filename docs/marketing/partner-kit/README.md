# Ledra 販売代理店 募集・パートナープログラム資料

> これから Ledra の販売代理店（パートナー）になっていただく企業・個人事業主の皆さまに、**「Ledra を扱うとどんなメリットがあるか」「報酬はどう発生するか」「どう始めるか」** をお伝えするための募集・勧誘資料セットです。
>
> **対象読者**: Ledra の販売代理店候補（自動車販売・保険代理店・ボディショップ・コーティング店・カーケア事業者・その他法人/個人事業主）
> **想定シーン**: 代理店勧誘の初回面談・説明会・パートナー募集 LP からの問い合わせ対応・申込前のクロージング
> **最終更新**: 2026-06-21

## ⚠️ 「代理店向け資料」の2系統について

Ledra には用途の異なる代理店向け資料が2系統あります。混同しないようご注意ください。

| 系統 | 場所 | 誰に渡すか | 目的 |
|---|---|---|---|
| **① パートナー募集資料（本キット）** | `docs/marketing/partner-kit/` | **これから代理店になる候補者** | 「Ledra の代理店になってもらう」ための勧誘・説明 |
| **② 営業キット** | [`docs/marketing/sales-kit/`](../sales-kit/README.md) | 契約済みの代理店が使う | 代理店が**施工店へ売る**ための営業ツール |
| **③ デモ説明資料** | [`docs/agent-demo-guide.md`](../../agent-demo-guide.md) | 契約済みの代理店が使う | 代理店が**施工店に実演する**ためのデモ手順 |

> **流れ**: まず本キット（①）で代理店になっていただき → 承認後に営業キット（②）とデモ資料（③）を使って施工店を開拓いただく、という関係です。

## 募集トークの基本の型（クロージングの流れ）

1. **市場の追い風（5分）** — 資料1の「いま代理店になる理由」で、自動車アフターマーケット × 証明・改ざん検知という市場の伸びしろを伝えます。
2. **報酬の魅力（10分）** — 資料2で、**一度の紹介が継続課金に連動して毎月積み上がるストック型報酬**であることを説明します。ここが最大の訴求点です。
3. **始めやすさ（5分）** — 資料3で「在庫不要・初期費用ゼロ・オンライン申込・最短3〜5営業日で承認」を伝え、ハードルの低さで背中を押します。
4. **支援体制（5分）** — 営業資料・デモ環境・研修・ランキング特典がそろっており、**未経験でも売れる仕組み**があることを伝えます。
5. **クロージング** — その場で `/agent/apply` を一緒に開き、申込まで伴走します。

> **困ったときの原則**: その場で答えられない条件面（料率・支払サイト・契約期間など）は、推測で答えず「Ledra 運営（パートナー窓口）に確認して折り返します」と伝えてください。誤った条件提示は契約後のトラブルになります。

## まず押さえる5語（最初に共有する用語）

| 用語 | やさしい説明 |
|---|---|
| **施工証明書** | 「いつ・誰の車に・どんな施工をしたか」を残すデジタル証明書。Ledra が売る中心の価値です。 |
| **コミッション（紹介報酬）** | 代理店が施工店を紹介し、その施工店が有料契約を続けている間、代理店に支払われる報酬です。 |
| **ストック型報酬（リカーリング）** | 1回売って終わりではなく、紹介先が使い続ける限り**毎月**入り続けるタイプの報酬です。 |
| **紹介リンク** | 代理店ごとに発行される追跡用 URL。ここ経由で登録された施工店が自動で自分の実績になります。 |
| **代理店ポータル** | 紹介・報酬・資料・契約書を管理する代理店専用画面（`/agent`）。承認後に使えます。 |

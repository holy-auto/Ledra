# 【資料3】申込・審査・オンボーディングの流れ

> Ledra 代理店になるための申込から、承認後に営業を開始するまでのステップ・必要情報・FAQ をまとめました。
> 申込はすべてオンラインで完結します。

---

## 1. 全体の流れ（最短 3〜5 営業日で承認）

```
①申込           ②審査            ③承認・アカウント発行   ④オンボーディング   ⑤営業開始
オンラインで  →  Ledra運営が  →   代理店ポータルの    →  資料DL・デモ確認 → 紹介リンクで
情報を入力       内容を確認        ログイン情報を発行       ・研修              施工店を開拓
（/agent/apply）  （3〜5営業日）                          （/agent）
```

申込状況はいつでも `/agent/apply/status` で確認できます。

---

## 2. 申込（`/agent/apply`）で入力する内容

オンラインフォームで以下を入力します。所要 5〜10 分程度です。

| 項目 | 必須 | 補足 |
|---|---|---|
| 会社名 | ✅ | 個人事業主の場合は屋号 |
| 担当者名 | ✅ | |
| メールアドレス | ✅ | ログイン済みなら自動入力されます |
| 電話番号 | ✅ | |
| 住所 | ✅ | |
| 業種 | 任意 | 自動車販売／保険代理店／ボディショップ／コーティング専門店／洗車・カーケア／その他 から選択 |
| 保有資格・許認可 | 任意 | 古物商許可など、信頼性の補強になるもの |
| 営業実績・販売チャネル | 任意 | 既存の顧客基盤・地域ネットワークなど |
| 添付書類 | 任意 | 会社案内・許認可証など **最大5ファイル** |
| 利用規約への同意 | ✅ | チェックが必要です |

> **ヒント**: 業種・実績・添付書類は任意ですが、入力があると審査がスムーズです。既存の顧客基盤や自動車関連業種は特に評価されます。

---

## 3. 審査について

- Ledra 運営が申込内容を確認します。**通常 3〜5 営業日** で結果をご連絡します。
- 審査では、事業実態・自動車アフターマーケットとの関連性・コンプライアンス面などを総合的に確認します。
- すでに代理店登録済みのアカウントからは再申込できません（その旨が表示されます）。
- 結果・進捗は `/agent/apply/status` とメールで確認できます。

---

## 4. 承認後にできること（オンボーディング）

承認されると代理店ポータル（`/agent`）にログインでき、以下がすぐ使えます。

| やること | 場所 | 目的 |
|---|---|---|
| 営業資料をダウンロード | `/agent/materials` | 料金表・比較表・パンフレット・契約書テンプレ等 |
| デモ環境を触る | [`agent-demo-guide.md`](../../agent-demo-guide.md) | 施工店・保険会社・顧客の各画面を実演で体感 |
| 操作ガイドを確認 | `/agent/operation-guide` | 施工店に見せる公式ガイド（公開 URL `/guide` も共有可） |
| 研修を受ける | `/agent/training` | 提案の型・製品知識を学ぶ |
| 紹介リンクを発行 | `/agent/referral-links` | 追跡用 URL を作って配布・成約を自動計上 |
| メンバーを招待 | `/agent/members` | チームで運用する場合 |

> **最初の3ステップ（推奨）**: ①営業資料を一式ダウンロード → ②デモアカウントでひと通り操作 → ③紹介リンクを発行して最初の1件に声をかける。

## 5. 営業の進め方（承認後はこちらへ）

承認後の「施工店への売り方」は、別系統の **営業キット** と **デモ説明資料** に詳しくまとまっています。

- 施工店への提案の型・料金説明・利用規約のかみくだき → [`docs/marketing/sales-kit/`](../sales-kit/README.md)
- デモアカウント情報・ポータル別の実演シナリオ・想定 FAQ → [`docs/agent-demo-guide.md`](../../agent-demo-guide.md)

## 6. よくある質問（申込・運用編）

**Q. 申込にお金はかかりますか？**
A. いいえ。申込・登録・営業資料・デモ環境の利用に費用はかかりません。在庫も不要です。

**Q. 個人事業主でも申し込めますか？**
A. はい。会社名欄に屋号を入れてお申し込みください。事業実態が確認できることが前提です。

**Q. 承認までどのくらいかかりますか？**
A. 通常 3〜5 営業日です。`/agent/apply/status` で進捗を確認できます。

**Q. 自分の店でも Ledra を使いながら、代理店もできますか？**
A. はい。むしろ「使いながら売る」スタイルは説得力が高く、おすすめです。施工店アカウントと代理店アカウントは両立できます。

**Q. ノルマや最低販売数はありますか？**
A. 制度上の条件はパートナー契約で定めます。最新の条件は Ledra 運営にご確認ください。

**Q. 契約書やテンプレートは用意されていますか？**
A. はい。施工店へ提示する契約書テンプレートや営業資料は `/agent/materials` から取得できます。運営が随時最新化します。

**Q. 資料は常に最新の内容ですか？機能が増減しても大丈夫？**
A. `/agent/materials` の「常に最新の商品資料」欄にある資料（サービス概要・機能紹介・料金プラン・比較表・セキュリティ・ROI）は、ダウンロードのたびにサーバーで自動生成されます。機能の追加・変更・料金改定があっても常に最新の内容で出力され、本部の差し替え作業は不要です。契約書テンプレートなど機能の増減と連動しない定型文書は、従来どおり運営が必要に応じて更新します。

**Q. 申込後に内容を修正したい場合は？**
A. `/agent/apply/status` から状況を確認のうえ、Ledra 運営（パートナー窓口）へご連絡ください。

**Q. 即答できない質問が来たらどうすればいい？**
A. 推測で答えず「持ち帰って Ledra 運営に確認します」が原則です。特に料率・支払条件・契約期間などの条件面は、誤った提示が後のトラブルになります。

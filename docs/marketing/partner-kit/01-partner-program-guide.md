# 【資料1】Ledra パートナープログラム案内

> Ledra の販売代理店（パートナー）になることをご検討中の皆さまへ。
> 「Ledra とは何か」「なぜいま代理店になるとよいか」「どんな報酬・支援が得られるか」を1冊にまとめました。
> 専門用語には **★やさしい解説** を付けています。

---

## 🤝 売るのは「在庫」ではなく「信頼の仕組み」。

> **Ledra（レドラ）** は、自動車のコーティング・PPF・ボディリペア・整備などの
> **施工の事実を、改ざんできないデジタル証明書として残せる SaaS** です。

代理店の皆さまは、この Ledra を施工店（コーティング店・板金塗装店・整備工場・カーディーラー等）に紹介していただきます。
**在庫を抱える必要も、配送も、サポート対応もありません。** 紹介と提案に集中でき、契約後の運用・サポートは Ledra 運営が担います。

> **★SaaS（サース）とは**: インターネット経由で使うソフト。お客さま側はインストール不要でブラウザですぐ使えます。アップデートや保守は提供者側が行うため、代理店が技術サポートを背負うことはありません。

## いま、Ledra の代理店になる理由

### 理由①：市場に強い追い風がある

- 中古車の品質透明化、保険の不正請求対策、施工品質の「見える化」——自動車アフターマーケットでは **「施工が本物であることを証明したい」というニーズが急速に高まっています。**
- 紙の証明書・口頭の説明では、もはや差別化も信用補強もできません。Ledra は **写真付き＋ブロックチェーン改ざん検知** で、この課題に正面から応えます。
- 競合の多くは「業務管理ソフト」止まり。Ledra は **証明書を保険会社・中古車流通までネットワークでつなぐ** 設計で、提案ストーリーを描きやすい商材です。

### 理由②：一度の紹介が「毎月」積み上がる（ストック型報酬）

- Ledra は月額サブスクリプション（後述）。代理店の報酬は **紹介先が課金を続けている間、継続的に発生** します。
- フロー型（売り切り）ではなく **ストック型**。紹介先が増えるほど、何もしない月でも報酬のベースが積み上がります。
- 詳細は [`02-commission-and-rewards.md`](./02-commission-and-rewards.md) を参照。

> **★ストック型報酬（リカーリング）とは**: 「1回売って終わり」ではなく、紹介したお客さまが使い続ける限り毎月入り続ける報酬。積み上げ式なので、続けるほど安定収入になります。

### 理由③：始めるハードルが圧倒的に低い

| 項目 | Ledra パートナー |
|---|---|
| 初期費用 | **ゼロ** |
| 在庫・仕入れ | **不要** |
| 申込方法 | **オンラインで完結**（`/agent/apply`） |
| 審査期間 | **最短 3〜5 営業日** |
| 技術知識 | 不要（営業資料・デモ環境・研修を完備） |
| 商談ツール | 公式営業キット・デモアカウントを無償提供 |

### 理由④：未経験でも売れる「支援フルセット」

承認後、代理店ポータル（`/agent`）から以下がすべて使えます。

- **営業資料の即時ダウンロード**（料金表・比較表・パンフレット・契約書テンプレート等／運営が随時更新）
- **デモ環境**：施工店・保険会社・顧客の各画面を、その場で実演できる読み書き可能なデモアカウント
- **公式デモ手順書**（[`agent-demo-guide.md`](../../agent-demo-guide.md)）でトークまで用意
- **研修・キャンペーン**：学習コンテンツと期間限定特典（コミッションUP 等）
- **ランキング**：実績上位の代理店は露出・特典面で優遇

## 何を売るのか — Ledra の価値（施工店に刺さる3本柱）

代理店として施工店に説明する中心はこの3つです。

### ① 施工証明書 × 改ざん検知
施工内容と写真を入れるだけでデジタル証明書を発行。発行後はブロックチェーンに記録され、後から書き換えられません。QR・URL で誰でも真正性を確認できます。

> **★ブロックチェーン・アンカリングとは**: 証明書の"指紋"を改ざんできない台帳に刻む技術。発行ボタンを押すだけで自動実行され、難しい操作は不要です。

### ② 部品装着インテグリティ（装着部品の本物保証）
取り付けた部品が本物であることを、装着記録 → AI 自動検査 → 納品書照合 → 確定署名 → ブロックチェーン記録 → 納車時のお客さま確認、という流れで証明します。

### ③ AI 業務自動化
証明書の下書き、写真チェック、請求・見積の起票、フォローメール、口コミ分析、塗膜厚の異常検知まで、複数の AI が事務作業を肩代わり。「人手が足りない」店ほど刺さります。

> さらに詳しい施工店向けの説明は、営業キットの [`04-shop-brochure.md`](../sales-kit/04-shop-brochure.md) をそのままお使いいただけます。

## 料金プラン（施工店が支払う金額 ＝ 報酬のベース）

代理店報酬は、紹介先がどのプランを契約するかに連動します。プランの全体像を押さえておきましょう。

| プラン | 月額 | 主な対象 |
|---|---|---|
| フリー | ¥0 | まず試したい施工店（証明書 月10件まで） |
| スターター | ¥9,800 | 本格活用を始める単店舗 |
| スタンダード（推奨） | ¥24,800 | 複数店舗・チーム運用 |
| プロ | ¥49,800 | 大規模運用・API 連携 |

- コミッションの計算ベースは **主契約（メインプラン）の月額請求額**です。プランが上位になるほど報酬ベースも大きくなります。
- フリープランは無料なので報酬対象外ですが、**「まず無料で始められる」は最強のクロージング材料**。無料で価値を体感した店舗が有料へ移行する流れを作るのが代理店の腕の見せどころです。

> アドオン（追加店舗・追加ユーザー・ブランド証明書 ¥3,300〜/月 等）の扱いを含む正確な報酬対象範囲は [`02-commission-and-rewards.md`](./02-commission-and-rewards.md) を参照してください。

> 最新の料金・キャンペーン（例: 先着100店舗限定の初期費用ゼロ施策）は、営業キットの [`01-pricing-and-features.md`](../sales-kit/01-pricing-and-features.md) をご確認ください。料金は改定される場合があるため、商談前に最新版を取得してください。

## こんな企業・人が向いています

- **自動車販売・ディーラー**：納車時に施工証明をセット提案でき、自社の付加価値にもなる
- **保険代理店**：施工の真正性を扱う商材と親和性が高い
- **ボディショップ・コーティング店・カーケア事業者**：自店で使いながら同業に紹介できる（使用者＝最強の営業）
- **既存の顧客基盤・地域ネットワークを持つ法人/個人事業主**

> 自店で Ledra を導入しつつ近隣店を紹介する「使いながら売る」スタイルは、説得力が高く成約率も上がります。

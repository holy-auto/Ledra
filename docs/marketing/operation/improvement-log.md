# HP 改善ログ

公開HPに対する**日々の改善の記録**です。`daily-ops`（Cowork）が日次で追記し、週次/月次の振り返りで参照します。
新しい日付を**上に**追記してください（降順）。1 改善 = 1 行。

## 記法

```
### YYYY-MM-DD
- [種別] 対象: 変更の要約（PR: #番号 or リンク） — 効果仮説/計測
```

- 種別: `meta` / `alt` / `cta` / `rewrite` / `seo` / `faq` / `content` / `note`
- 「本日は対応なし」の日も 1 行残すと運用が追える。
- 効果は分かる範囲で（GSC/GA4/PostHog のどれで測るか）。後日、週次/月次レポートで結果を追記してよい。

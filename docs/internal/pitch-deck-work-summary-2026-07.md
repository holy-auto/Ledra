## 2. v2 で変えたこと（当初の 5 分版からの改訂方針）

1. **身近な課題・当事者意識**: 課題を「数字」ではなく **"あなたの1日 / 体験"** で描く（施工店 17 時間・お客様"保証書どこ"・次の買い手"本当に施工済み？"）。
2. **After 先出し**: 「Ledra のある1日」を解決の前に見せ、**付加価値を先に体感**させる。
3. **一気通貫の効き目を 3 段で**: **固定費↓ → 浮いた時間を売上業務へ再配分 → 証明が資産化**。「削るだけの SaaS ではなく、削った上に新資産が積み上がる」。
4. **利用者別メリット＋正直なハードル**: 図解では 4 者すべて見せて網羅性を担保しつつ、**視覚と語りの主役は施工店・お客様**、保険・中古車 OEM は「上流も得する」脇役。弱点を隠さず信頼に変える。共通結論 **"早く入るほど得をする"**。
5. **調達額はスライドに出さない**: 締めは **非数字 CTA（出資検討 / PoC / 加盟 / 採用いずれも歓迎）**。市場 5.5 兆円 × 3 階建て ARR は投資家向けに事業性スライドで温存、調達目線は面談・口頭で。

# プロダクト概観

## 業務 SaaS と証明書ネットワークが地続きの 1 プロダクト

# 施工証明書の差別化

## 発行して終わり、ではなく検証され続ける証明書

```
[施工完了]
   ↓ 写真 + 施工内容入力
[Ledra 証明書発行]
   ↓ 写真ハッシュ (SHA-256)
[Polygon アンカリング]
   ↓ 改ざん検知保証
[QR / URL で公開検証]
   ← 顧客・保険会社・中古車市場が参照
```

- **QR / 公開 URL** `/c/[public_id]` でブラウザから誰でも検証
- **Polygon on-chain アンカリング** で写真改ざんを検知
- **C2PA + NFC タグ連携** で物理車両 × デジタル証明書を結ぶ

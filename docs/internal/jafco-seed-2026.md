## 0. ミッション

```
職人の技術を、次へつなぐ。
```

「次へつなぐ」3 つの軸:
- **記録**: 紙の作業伝票で散逸していた施工記録を、改ざん不能なデジタル証明書として次のオーナー・保険査定・中古車流通へ承継
- **技能**: ベテラン職人の暗黙知を Ledra Academy を通じて次世代の職人へ承継
- **価値**: 施工で生まれた付加価値を、保険査定の客観指標・中古車流通時の再評価・顧客 LTV として次の経済的価値へ承継

## 9. ピッチデック

実装場所: `src/app/pitch/jafco/page.tsx`

### ローカル確認手順

```bash
npm run dev
# ブラウザで http://localhost:3000/pitch/jafco を開く
# 矢印キー / スペースで進行、左矢印で戻る
```

### PDF 出力手順

1. `/pitch/jafco` を開いた状態で右上「PDF出力」ボタン or `Cmd+P`
2. プリンター: 「PDF として保存」を選択
3. レイアウト: 横向き / 用紙サイズ: A4 / 余白: なし / 倍率: 100%
4. ヘッダー・フッターのオフ
5. 「背景のグラフィック」を ON
6. `Ledra-JAFCO-SEED-2026.pdf` として保存

### Google Drive アップロード手順

1. Google Drive にログイン
2. 「Ledra - JAFCO SEED 2026」フォルダを新規作成
3. PDF をアップロード
4. 右クリック → 「共有」→ 「リンクを取得」
5. 「リンクを知っている全員」「閲覧者」に設定
6. リンクをコピーして応募フォームに貼り付け

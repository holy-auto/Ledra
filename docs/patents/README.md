## 0.5. 取得確率 × 優位性での推奨（2026-06 追補）

「取得確率の高いもの／取得できれば優位なもの」を問われた際の答え。**両軸の決め手は『未公開か（新規性）』＋『暗号・DB 機構という技術的性格（進歩性・発明該当性）』**。

| 候補 | 公開状況 | 取得確率 | 優位性 | 位置づけ |
|---|---|---|---|---|
| **06 ZKP 選択的開示** | **完全未公開** | **◎ 高** | **◎ 高** | **★単独で出すならこれ（両軸で最有力）** |
| **07 確定ゲート（部品インテグリティ）** | **完全未公開** | ◎〜○ | **◎ 高** | **★最強の防御の堀** |
| 01 メタアンカー | コンセプト公開済／機構は未公開 | △〜○（要・請求項絞り） | ◎ | 背骨。機構（U1/U2）に絞れば出願価値あり |
| 03 ガードレール | 未公開 | ○（ビジネス関連発明） | ○ | 統合＋非対称failureで狭く |
| 02 改ざんカスケード | 未公開 | △（進歩性が論点） | ○ | 単独より 06/07 の従属項に束ねる |

- **なぜ 06/07 が 01 より「取得確率」で上か**：01 は「VIN 横断集約」コンセプトを 2026-05-04 から自社開示済み（[棚卸し 04](./04-disclosure-inventory.md) D5）で広い独立項が取りにくい。06/07 は機構ごと完全未公開。
- **なぜ 06/07 が 02/03 より「取得確率」で上か**：06（Merkle/HMAC/コミットメント）・07（DB トリガ強制/鍵付きハッシュ/署名）は技術的性格が明確で、発明該当性・進歩性が「ビジネス手法すぎる」方向に流れにくい。
- **3 発明は連結**：07 の `content_hash` → 01 の車両メタアンカーに合流 → 06 のコミットメントに確定状態を秘匿クレームとして取り込み。1 出願（複数独立項）に束ねる選択肢も弁理士と相談。

## ⚠️ 全件共通の最重要注意：出願タイミング（新規性）

特許は **出願日より前に発明を公開すると、原則として新規性を失い権利化できません。**
Ledra は一部機能を既に本番公開しているため、件ごとに公開状況が異なります。

**→ 詳細は [04 公開状況の棚卸し](./04-disclosure-inventory.md) を参照（実コードで公開面を調査済み）。**

| 発明 | 公開状況（2026-06-05 時点） | 出願余地 |
|---|---|---|
| **06 ZKP 選択的開示** | **機構（選択的開示・コミットメント・nonce 設計）は完全未公開**（grep 0 件）。保険会社向け検証 API は認証の背後で一般公開なし。 | **広い独立項の余地あり（自社開示ハンデなし）。出願までアルゴリズムを対外的に語らない。** |
| **07 確定ゲート（部品インテグリティ）** | **機構（DB 強制確定・連絡先格下げ・横断シリアル照合）は完全未公開**。設計書・実装とも社内のみ。 | **余地あり。組み合わせを進歩性の中心に。出願まで詳細非公開を維持。** |
| 01 メタアンカー | **機構（集約ダイジェスト＝単一Tx）は未公開**。ただし「VIN横断で施工履歴を集約」コンセプトは `/features/timeline`・`/poc` で **2026-05-04 から公開済み**。`/v/`・API は `PASSPORT_PUBLIC_ENABLED` で未公開。 | **機構に絞れば余地あり。コンセプト級の広い請求項は自社開示で不可。最優先で請求項を絞る。** |
| 02 改ざん検出 | アルゴリズム（EXIF三分類＋灰のみVision）は外部非公開。「改ざん検知あり／C2PA／SHA-256」は公開済み。 | 方法に限れば可。HP・PoC でアルゴリズムを語らない。 |
| 03 ガードレール | 管理画面に設定 UI あり（挙動は契約テナントに可視）。内部アルゴリズムは非公開。 | UI 公開＝発明の公開とまでは言い切れないが、要弁理士確認。 |

- 既に本番運用中の **画像単位アンカー（Phase 1）単体は新規性を失っている可能性が高い**。01 は「Phase 1 の上に乗る集約レイヤー（メタアンカー）」を発明として切り出している点に注意。
- 日本には新規性喪失の例外（特許法 30 条 / 公開後 1 年の救済）があるが、**形式要件があり、第三者の独自公開は救えない**ため「公開前出願」が原則。
- **アクション**: 01 については、対外公開（`PASSPORT_PUBLIC_ENABLED=true` 化、HP 掲載、プレスリリース、PoC 資料配布）の前に弁理士へ相談すること。

## 先行技術の既知リスク

- ホンダが「車両情報を NFT としてブロックチェーンに記録」する特許を **3 件出願済み**（2024 Q1、`docs/research-blockchain-automotive-japan-2026.md` 参照）。

- → 01 は必ずプロの先行技術調査を通すこと。差別化軸は「**複数の独立事業者をまたいだ集約**」と「**サーバ非依存の第三者再計算検証**」。

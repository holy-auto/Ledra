## 3. J-PlatPat 検索手順（自分でやる一次チェック）

[J-PlatPat](https://www.j-platpat.inpit.go.jp/) → 「**特許・実用新案**」→「**特許・実用新案検索**」。

- **選択入力**が簡単：各「検索キーワード」欄に**1つの概念バケット**を入れ、**欄内はカンマ区切り＝OR**、**欄をまたぐと AND**。検索対象は「要約／請求の範囲」または「全文」を選ぶ。
- 分類で絞るときは「**特許分類**」欄に **IPC** を入力（下記コード）。FI/Fターム は「**特許分類照会（PMGS）**」で確認してから使う。
- まず **IPC（H04L 9/50 等）× キーワード少数**で母集合を作り、ヒット数を見ながらキーワードを足して絞る（角渕/中島IP事務所の解説と同手順）。
- 近接ヒットは「**経過情報**」で生死（登録/拒絶/みなし取下）を確認。**生きている登録特許**が最重要。

### 3-1. 使う分類コード（IPC/CPC：母集合作りに有効）
| コード | 意味 | 主対象 |
|---|---|---|
| **H04L 9/50** | 暗号機構のうち**ハッシュチェーン＝ブロックチェーン／ハッシュツリー**を用いるもの | 01・06・07（アンカー/Merkle） |
| **H04L 9/32** | 利用者の同一性・権限の検証（ハッシュ・**電子署名**を含む） | 06・07（署名/認証） |
| H04L 9/3236 / 9/3247 / 9/3297 | ハッシュ関数／電子署名／**タイムスタンプ**（※下位コードは要確認） | 07（署名・TSA） |
| **G06F 21/64** | **データの完全性の保護** | 01・07（不変記録） |
| G06F 21/62 / 21/31 | データアクセス保護・プライバシー／利用者認証 | 06（秘匿）・07（本人認証） |
| **G06Q 40/08** | **保険** | 06・07（保険連携） |
| G06Q 10/00 / 50/* | 管理・事業／各種サービス（中古車・整備は明確な枠が薄い） | 01（履歴管理） |

> Fターム（JP固有・**PMGS で要確認**）：暗号・認証は **5J104**、コンピュータの機密保護は **5B285**、ビジネス関連は **5L** 系が候補。確定前に J-PlatPat の分類照会で当てること。

## 4. 各発明の推奨アクション（予備調査を受けて）

1. **01**：広いコンセプトは先行密集が確定的（WO2018014123A1・MOBI・ホンダ）。**請求項を「ソート連結→単一Tx集約→第三者再計算」の機構に絞る**方針を維持（提案書01 §6/§9 のとおり）。WO2018014123A1 の独立項を弁理士に最優先で読ませる。
2. **06**：汎用 Merkle 選択的開示は公知。**「車両部品×保険＋開示/非開示/粗粒度混在＋シークレット nonce による低エントロピー秘匿値保護」の組合せ**に独立項を限定。VC/SD-JWT/BBS+ 系を弁理士調査でクリアランス。
3. **07**：部品真贋は先行あり。**「本人所持証明に束ねた確定をDB層で運営者も例外なく強制＋連絡先出所格下げ＋生値非開示の横断シリアル照合」**を進歩性の中心に。US20210119771A1 を弁理士に読ませる。
4. **共通**：上記検索式で生きている登録特許がヒットしたら、本ファイルの §2 表に追記し、各提案書 §9 に反映。**出願前の対外公開は引き続き凍結**（[05 §F](./05-attorney-consultation-request.md)）。

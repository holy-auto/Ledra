# JPO様式（電子出願）変換テンプレート — 使い方

> 目的：`drafts/明細書-*.md`（Markdown）を、特許庁の**インターネット出願ソフト**に取り込める**HTML様式**へ変換するためのひな形と規則。
> ⚠️ **様式・文字コード・画像仕様は改訂され得る**。提出前に必ず**[電子出願ソフトサポートサイト](https://www.pcinfo.jpo.go.jp/)**の最新仕様（DTD・記載要領）で検証すること。本テンプレは一般的な慣行に基づく代表例。

---

## 1. 提出書類の構成（特許）

電子出願では、以下を**別書類**として作成し、インターネット出願ソフトで1つの出願にまとめる。

| 書類 | テンプレ | 備考 |
|---|---|---|
| 願書 | （ソフトで作成） | 出願人・発明者・整理番号等。識別番号・電子証明書が必要 |
| **明細書** | [明細書.template.html](./明細書.template.html) | 本体 |
| **特許請求の範囲** | [特許請求の範囲.template.html](./特許請求の範囲.template.html) | 権利範囲＝最重要 |
| **要約書** | [要約書.template.html](./要約書.template.html) | 概要（権利範囲に影響せず） |
| **図面** | [図面.template.html](./図面.template.html) | 画像を参照。`figures/*.svg` をラスタ変換して使用 |

---

## 2. 記載様式の規則（要点）

- **形式**：HTML（特許庁DTD準拠）。本テンプレは表示確認用にUTF-8で記述。**取り込み時はソフト指定の文字コード（従来 Shift_JIS）**へ変換する（要確認）。
- **項目見出し**：`【書類名】`『【発明の名称】』等の **`【　】` は“文字”としてそのまま記載**（特殊タグではない）。各行末は `<BR>`。
- **段落番号**：`【０００１】` のように**全角数字4桁の連番**を、各段落の先頭に付す。**請求項・要約・図面には段落番号を付さない**。
- **字下げ**：段落本文の冒頭は**全角スペース1字**。
- **英数字・記号**：原則は全角だが、式・符号・英数字列は半角でよい（読みやすさ優先、要領に従う）。`||`（連結）等の記号は本文中で説明的に用いる。
- **数式・特殊記号**：複雑な式は**画像化**して図面で参照するのが無難。
- **禁止事項**：色・装飾は不可（モノクロ前提）。リンク・スクリプトは不可。

---

## 3. 図面の規則（重要）

- 図面は**別書類**。各図は `【図１】` ラベル＋画像。
- 画像は**白黒（又はグレースケール）の線画**。**カラー不可**。形式・解像度・寸法・容量に上限あり（GIF/BMP等。**要・最新仕様確認**）。
- 本リポジトリの図は `drafts/figures/*.svg`（編集マスタ）。提出時は **SVG → 規定のラスタ形式（白黒）** へ変換し、線幅・文字サイズを線画基準に調整。
- mermaid（各明細書内）も同様にラスタ化して用いる。

---

## 4. Markdown → HTML 変換手順

1. `明細書-06/07/01.md` の **`【書類名】明細書` 〜 `【符号の説明】`** を `明細書.template.html` の本体へ流し込む。
2. **段落番号を全角4桁連番に振り直す**（mdの【0001】→【０００１】、欠番・重複に注意）。各段落末に `<BR>`、字下げに全角空白。
3. `【特許請求の範囲】` を `特許請求の範囲.template.html` へ。**請求項番号は全角**（【請求項１】）。
4. `【要約書】` を `要約書.template.html` へ。要約は**概ね400字以内**に収める。
5. mermaid/`figures/*.svg` を白黒ラスタ化し、`図面.template.html` に `【図１】`＋画像で配置。
6. インターネット出願ソフトで各HTMLを取り込み→**形式チェック（文書チェック）**→ 願書と束ねて送信。
7. 送信後の**出願審査請求（3年以内）**・減免・早期審査は [09](../../09-filing-guide.md)。

---

## 5. 注意（本案件固有）

- **01 は30条**：願書での主張と出願後の証明書提出（[10](../../10-art30-novelty-exception.md)）。様式・期限は弁理士/JPO確認。
- **公開凍結**：出願前に中核機構を公開しない（[05 §F](../../05-attorney-consultation-request.md)）。
- 変換後は**必ず文書チェック**でエラーを潰してから送信。

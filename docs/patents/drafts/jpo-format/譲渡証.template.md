# 譲渡証書（特許を受ける権利）テンプレート

> 用途：**職務発明規程が無い／個別に承継を明確化する場合**に、発明者（個人）から法人へ「特許を受ける権利」を譲渡したことを証する書面。
> ⚠️ 法的助言ではない雛形。**文言・押印・相当の利益（対価）の扱いは弁理士／法務で確認**。職務発明規程がある場合は規程で発生時から法人帰属とすることも可（特許法35条。[法人出願チェックリスト §3](../法人出願-準備チェックリスト.md)）。
> 出願時に提出は通常不要だが、社内で**権利移転の連鎖（chain of title）**として保全する。

---

```
譲　渡　証　書

　譲渡人は、譲受人に対し、下記発明に係る「特許を受ける権利」の全部を譲渡したことを
　証します。

記

１．発明の表示
　　発明の名称：〔例：車両部品の装着に関する選択的開示証明方法、システム及びプログラム〕
　　整理番号　：〔例：HA-ZKP-001〕
　　（出願番号が付与済みの場合）出願番号：〔特願____-______〕

２．譲渡の対象
　　上記発明について日本国及び外国において特許を受ける権利の全部
　　（優先権を主張する権利、外国出願をする権利を含む。）

３．譲渡日　　令和〔　〕年〔　〕月〔　〕日

　譲渡人（発明者）
　　住　所：〔発明者の住所〕
　　氏　名：〔発明者氏名〕　　　　　　　　㊞

　（共同発明者がいる場合は各人について上記を記載・各人の譲渡を得る）

　譲受人
　　所在地：〔本店所在地〕
　　名　称：〔holy-auto株式会社〕
　　代表者：代表取締役　〔氏名〕　　　　　㊞
```

---

## 留意点
- **共同発明者**が複数いる場合、**全員から**それぞれ譲渡を得る（一人でも欠けると持分の瑕疵）。
- **役員・業務委託先・社外共同発明者**は職務発明規程が及ばないことがあるため、**個別の譲渡証で明確化**。
- **相当の利益（対価）**：職務発明規程がある場合は規程に従う。規程が無い場合の対価の扱いは法務／弁理士に確認。
- 外国出願・PCTを見据え、**外国で特許を受ける権利・優先権主張の権利**も譲渡対象に含める文言にしてある。
- 押印・電子署名の要否は社内規程／提出先に従う（社内保全目的なら電子署名でも可）。

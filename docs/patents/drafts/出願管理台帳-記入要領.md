# 出願管理台帳 — 記入要領

> `出願管理台帳.csv` の使い方。表計算ソフトに取り込んで運用する。**期限の正確な月数/日数・現行料金は特許庁(JPO)で要確認**（[09](./../09-filing-guide.md)・[10](./../10-art30-novelty-exception.md)）。

## 列の意味と期限の計算規則

| 列 | 意味 / 計算規則 |
|---|---|
| 整理番号 | 出願人管理番号。`HA-<ZKP/GATE/META/PIPE>-NNN`（[jpo-format §6](./jpo-format/README.md)） |
| 発明 | 06/07/01/統合 |
| 出願種別 | 国内 / PCT / 分割 / 優先権主張 |
| 出願番号・出願日 | 出願後にJPOから付与・確定 |
| 公開番号・公知日 | 出願公開（**出願日＋1年6月**で自動）後に記入 |
| **審査請求期限** | **＝出願日＋3年**。徒過すると取下げ擬制（審査されない）。最重要 |
| 審査請求日 | 請求した日（減免申請も同時に） |
| **30条主張** | 自社開示があるか。06/07＝不要。**01＝要**（[10](./../10-art30-novelty-exception.md)） |
| **30条証明書提出期限** | 30条主張時、**＝出願日＋所定日数（実務上30日・要確認）**。徒過＝例外不適用 |
| 拒絶理由通知日・応答期限 | 中間処理。応答期限（指定期間）を厳守 |
| 登録番号・登録日 | 査定→登録後 |
| 次回年金期限 | 登録後の特許料（年金）納付期限。徒過＝権利消滅 |
| 優先期限_12月 | **＝出願日＋12月**。パリ優先権でPCT/外国出願する最終期限 |
| PCT移行期限_30_31月 | **＝優先日＋30/31月**（国により異なる）。各国国内移行の期限 |
| ステータス・担当・メモ | 運用用 |

## 運用のコツ
- **期限はカレンダー/リマインダにも二重登録**（審査請求＋3年、30条＋30日、優先＋12月、年金）。
- 減免（中小・スタートアップ）該当なら審査請求料・特許料が大幅減（[09 §3](./../09-filing-guide.md)）。メモ欄に減免区分を記録。
- 分割・優先権主張で新出願が増えたら整理番号を連番加算して行追加。
- **01は出願前に30条の起算日（自社開示日）を確定**してからでないと期限計算ができない（[10 §2/§3](./../10-art30-novelty-exception.md)）。

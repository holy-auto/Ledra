# 法人で出願する場合の準備書類・手続チェックリスト

> 対象：**株式会社HOLY（法人）を出願人**として特許出願する場合の、個人出願と異なる準備物。（Ledra＝製品名／holy-auto＝GitHub組織名）
> ⚠️ 実務メモ（法的助言ではない）。**識別番号・電子証明書・減免の必要書類・委任状要否は最新の特許庁(JPO)／法務局仕様で要確認**。
> 関連：[09 出願ガイド](../09-filing-guide.md)、[jpo-format（願書）](./jpo-format/README.md)、[10 30条](../10-art30-novelty-exception.md)。

## 0. 個人出願との主な違い（結論）

| 項目 | 個人 | **法人（株式会社HOLY）** |
|---|---|---|
| 電子証明書 | マイナンバーカード等（公的個人認証） | **商業登記に基づく電子証明書**（法務局発行）が標準 |
| 識別番号 | 個人に付与 | **法人に付与**（識別番号付与請求） |
| 願書の出願人 | 個人氏名・住所 | **商号（正式名称）・本店所在地・識別番号** |
| 発明者 | 本人 | **発明した自然人**（社員＝個人。法人は発明者になれない） |
| 権利の帰属 | 本人に原始帰属 | **職務発明の承継が必須**（下記§3。最重要） |
| 手数料・減免 | 個人区分 | 法人区分。**中小・スタートアップ減免**は要件の証明書類 |

## 1. 事前に取得・登録するもの

- [ ] **法人の識別番号**：未取得なら「識別番号付与請求」。以後の手続は識別番号で行う。
- [ ] **商業登記電子証明書**：法務局（登記所）で取得し、**インターネット出願ソフトに登録**。電子出願の申請人認証・署名に使う。
  - 取得には電子証明書発行申請（登記所／オンライン申請システム）。有効期間・手数料は要確認。
- [ ] **手数料の納付手段**：予納台帳（予納）／口座振替／電子現金納付 等を法人名義で準備。

## 2. 願書（法人版）の記載

- 【特許出願人】【識別番号】〔法人の9桁〕／【氏名又は名称】株式会社HOLY／【住所又は居所】〒107-0061 東京都港区北青山1-3-1 アールキューブ青山3F
- **【代表者】**：識別番号と電子証明書が登録済みなら省略可のことが多いが、**ケースにより代表者氏名の記載・代表者の電子証明書が必要**（要確認）。
- 【発明者】【住所又は居所】【氏名】：**実際に発明した個人**を全員。法人名は書かない。誤記・遺漏は瑕疵の原因。
- テンプレ：[jpo-format/願書.template.html](./jpo-format/願書.template.html)（法人の出願人欄に記入）。
- 01は **30条主張ブロック**を有効化（[10](../10-art30-novelty-exception.md)）。

## 3. ★職務発明：権利の承継（法人出願の最重要・落とし穴）

発明者は**個人（社員）**。法人が出願人・権利者になるには、**「特許を受ける権利」を法人へ帰属させる手当**が必要（特許法35条）。これを欠くと**冒認出願（権利帰属の瑕疵）**になり得る。

2通り：
- **(A) 職務発明規程を整備（推奨）**：勤務規則等で「職務発明の特許を受ける権利を**発生時から法人に帰属**させる」旨と「**相当の利益**（対価）」を**あらかじめ**定める。これがあれば各発明の都度の譲渡が不要で、発生時から法人帰属（35条3項）。
- **(B) 個別譲渡（規程が無い場合）**：発明ごとに発明者から法人へ「特許を受ける権利」の**譲渡証**を取得（[譲渡証テンプレ](./jpo-format/譲渡証.template.md)）。

チェック：
- [ ] **職務発明規程の有無を確認**。無ければ (B) 譲渡証を全発明者分取得、並行して規程整備を検討。
- [ ] 発明者が**役員・業務委託・共同発明者（社外）**を含む場合は、各人からの承継/譲渡を個別に確認（業務委託先の発明は職務発明規程が及ばないことがある）。
- [ ] 共同発明・他社共同の場合は**共有持分・共同出願**の取り決め（持分・費用・実施）を別途。
- ※ 出願時に譲渡証の提出は通常不要だが、**権利移転の連鎖（chain of title）を社内で保全**。法人名で直接出願するのが最もクリーン（個人名で出してから移すと名義変更届が要る）。

## 4. 手数料・減免（法人）

- 出願料・**出願審査請求料**（大きい）・特許料は法人名義で納付（[09 §3](../09-filing-guide.md)）。
- **減免（中小・スタートアップ等）**：該当すれば審査請求料・特許料が**1/2〜1/3又は免除**。
  - [ ] 自社が該当区分か確認（中小企業／設立後一定年数・資本金等の要件）。
  - [ ] **減免の証明書類**を準備（区分により、登記事項証明書、確定申告書の写し、要件該当の宣誓等）。区分ごとに必要書類が異なるため要確認。

## 5. 代理人を立てる場合（弁理士）

- [ ] **委任状**：手続を弁理士に委任する場合に必要（手続の種類により要否が異なる。出願自体は不要なことも、中間処理で必要なことも）。
- 本人出願（法人自ら）なら委任状は不要。

## 6. 提出物件一式（法人・本人出願）

- [ ] 願書（出願人＝法人）
- [ ] 明細書／特許請求の範囲／要約書／図面（[drafts/](.) ＋ [jpo-format](./jpo-format/README.md)）
- [ ] （01のみ）30条主張＋出願後の証明書提出
- [ ] 手数料納付（減免該当なら減免申請＋証明書類）
- 〔社内保全〕職務発明規程 or 譲渡証、出願管理台帳（[出願管理台帳.csv](./出願管理台帳.csv)）

## 7. 進め方（法人）

1. **識別番号＋商業登記電子証明書**を取得・登録（先に着手。発行に時間がかかる）。
2. **職務発明の権利帰属を確定**（規程確認 or 譲渡証取得）。発明者の確定も。
3. 減免の該当・必要書類を確認。
4. 願書（法人）＋明細書一式を電子出願ソフトで作成→文書チェック→送信（06→07→01）。
5. 出願管理台帳に整理番号・期限を登録（[記入要領](./出願管理台帳-記入要領.md)）。

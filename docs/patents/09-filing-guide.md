## 0. 結論：弁理士は「必須ではない」が、要所だけは当てる

- 日本では**本人出願（自分で出願）が合法**。弁理士は法的義務ではない。
- ただし本案件は (a) **クレーム作成が価値の源泉**（暗号/DB機構）、(b) **01の30条は不可逆**、(c) **出願後は新規事項追加不可・先願主義**。
- **推奨ハイブリッド**：明細書ドラフトは本書＋[drafts/](./drafts/) で自前作成 → **少なくとも 01 の30条とクレーム範囲は単発相談 or 無料窓口でプロに1回当てる**。

| ルート | 費用目安 | 向き |
|---|---|---|
| 本人出願（フルDIY） | 特許庁料金のみ | コスト最小・権利品質リスク最大。**01は非推奨**（30条事故） |
| 本人出願＋単発相談/無料窓口 | ＋数千〜数万円 | **本命の最低ライン**。30条・クレーム範囲だけ当てる |
| 明細書は自前→弁理士レビュー/仕上げ | ＋10〜30万/件 | 06/07向け。工数圧縮しつつ品質確保 |
| 弁理士フル依頼 | 25〜60万/件 | 01や、海外（PCT）視野の本命 |

無料相談：**[知財総合支援窓口](https://chizai-portal.inpit.go.jp/)**（INPIT・全国・無料）、**日本弁理士会の無料相談会**。

## 1. 出願に必要な書類（特許）

| 書類 | 中身 | 本案件の素材 |
|---|---|---|
| **願書** | 出願人・発明者・あて先等の事務書類 | 出願時に作成（識別番号要） |
| **明細書** | 技術分野〜実施形態（発明の説明本体） | [drafts/明細書-06/07/01](./drafts/) |
| **特許請求の範囲** | 請求項（権利範囲）＝**最重要** | 各提案書 §7 ＋ drafts |
| **要約書** | 概要（権利範囲には影響しない） | drafts に同梱 |
| **図面**（任意だが推奨） | フロー図等 | 各提案書 §8（mermaid）→ 出願用に作図 |

> 明細書・請求項・要約・図面は**別書類**として提出（電子出願ではまとめてアップ）。drafts/ では1ファイルに章分けして収録。

## 2. 電子出願の手順（本人出願）

1. **識別番号の取得**（特許庁・初回のみ）。
2. **電子証明書**を用意（マイナンバーカード等の公的個人認証 or 商業登記電子証明書）。
3. **「インターネット出願ソフト」**（JPO提供）をPCにインストール。
4. 明細書等を**HTML/XML（JPO指定形式）**に整形して送信。
   - Word からの変換支援あり。drafts/ は Markdown なので、提出前に JPO 様式へ整形が必要。
5. 送信＝出願。**出願番号**が付与される。
6. **3年以内に「出願審査請求」**（しないと取下げ擬制＝審査されない）。

> 紙でも出せるが電子化手数料がかかる。電子出願が基本。

## 3. 料金（目安・現行はJPOで要確認）

| 段階 | 概算 |
|---|---|
| 出願料 | 約 14,000 円（電子） |
| 出願審査請求料 | 約 138,000 円 ＋ 4,000 円 × 請求項数（**大きい**） |
| 特許料（登録後・年毎） | 1〜3年で 年 数千円＋請求項数比例、以降逓増 |
| （任意）早期審査 | 手数料無料（要件あり） |

### 減免制度（スタートアップ/中小は必ず確認）
- **中小ベンチャー・小規模企業**等は **審査請求料・特許料が 1/2〜1/3 または免除**。
- 適用には法人区分等の要件・申請が必要。holy-auto が該当するか出願前に確認（該当なら審査請求料の負担が大きく下がる）。

## 4. 審査を早める（任意）

- **早期審査**：中小企業/ベンチャー、実施関連等の要件で、通常より大幅に早く審査。手数料無料。事情説明書を出す。
- **スーパー早期審査**：要件を満たせばさらに高速。
- 本案件は事業実施中（実装済み）なので早期審査の要件に乗りやすい。06/07を早く権利化したいなら有効。

---

## 5. 出願後にできない/注意（不可逆ポイント）

- **新規事項の追加禁止**：出願時の明細書・図面に**書いていないこと**は後から足せない。→ 出願前に実施形態・変形例を**広めに書き切る**。
- **先願主義**：同じ発明は**先に出した者**が勝つ。迷うなら早く出す。
- **公開**：出願から1年6月で**自動公開**（それまでは非公開）。公開後は誰でも読める。
- **30条（自社開示の救済）は出願時に手続**：[10](./10-art30-novelty-exception.md) 参照。**01は出願と同時に証明書段取りが要る**。

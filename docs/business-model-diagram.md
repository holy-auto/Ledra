## 3. ネットワーク効果の構造

```
        施工店が増える
              │
              ▼
     証明書の発行数が増える ───────────────────┐
              │                               │
              ▼                               ▼
   保険会社が参照価値を認める        中古車市場で「Ledra証明あり」が
              │                     付加価値になる
              ▼                               │
  保険会社が施工店に「Ledra使用」を            ▼
  推奨・指定 → 施工店が増える      証明あり車両が高値で売れる
                                             │
                                             ▼
                                  施工店の顧客満足度が上がる
                                  → 施工店がLedraを使い続ける
                                  → 施工店が増える (冒頭に戻る)
```

**二重ネットワーク効果**: 施工店数 × 証明書発行数が積み上がるほど、保険会社・中古車ポータルへの参照価値が高まり、それが施工店の採用動機を後押しする。

## 5. ピッチ用 1スライド版（口頭補足付き）

### スライド本体テキスト案
```
【Ledra のビジネスモデル】

収益構造: 3 階建て ARR

  ① 施工店サブスク        ¥9,800〜¥49,800/月
     ADD-ON               ブランド証明書・追加店舗・AI機能
                           → 目標 ARPU ¥35,000

  ② 保険会社 B2B API      ¥5M〜¥10M/社/月
                           → Lighthouse: 損保ジャパン

  ③ 流通・OEM API         中古車ポータル照会料 / OEM ホワイトラベル

ARR 目標 ¥10億 =  店舗 ¥6億 + 保険 ¥3億 + 流通 ¥1億
```

### 口頭補足（VC 向け）
> 「店舗 SaaS 単独だと 2,400 店が頭打ちになります。ただし施工証明書が保険会社の査定フローに組み込まれると、保険会社側の課金単価が 1 社で店舗サブスク 250 店分に相当します。これが保険 ARR ¥3 億の根拠です。証明書発行数が積み上がるほど、中古車ポータルへのデータ価値が高まり、第 3 階の流通課金も生まれます。店舗を取るだけでなく、証明書をネットワークにする設計が、この事業が大きくなれる理由です。」

## 6. 参考: ユニットエコノミクス試算

| 指標 | 値 | 根拠 |
|---|---|---|
| 平均 ARPU | ¥35,000/月 | Standard ¥24,800 + アドオン平均 ¥10,200 |
| 推定 CAC | ¥30,000〜¥50,000 | 直販 + 代理店経由の混合。Agent ポータルで代理店報酬 ¥10,000/紹介 |
| 推定 LTV | ¥35,000 × 24ヶ月 = ¥840,000 (2年想定) | 解約率 4%/月想定 |
| LTV / CAC | 16〜28 倍 | SaaS 基準 (≥3) を大幅超過 |
| CAC Payback | 1〜1.5ヶ月 | 早期黒字化の根拠 |

> 保険会社課金が乗ると LTV がさらに押し上げられる (Insurer ポータル経由で施工店の解約率低下が期待できる)。

# Ledra

Ledra は、飲食店（居酒屋など）向けの **QR コード方式モバイルセルフオーダーシステム** です。
お客様が自分のスマートフォンでテーブルの QR コードを読み取り、メニューの閲覧・注文・店員の呼び出しまでをブラウザ上で完結できます。

## 主な機能

### お客様向け画面（Customer App）

| 機能 | 説明 |
| --- | --- |
| QR コードスキャン | テーブルに設置された QR コードをスマホのカメラで読み取り、テーブル番号を取得します。カメラが使えない場合は手動でテーブル番号を入力することもできます。 |
| メニュー閲覧 | カテゴリ（すべて / 前菜 / メイン / サイド / ドリンク）でメニューを絞り込み、料理名・説明・価格を確認できます。 |
| カート | 選んだ商品をカートに追加し、数量変更・削除・合計金額の確認ができます。 |
| 注文 | カートの内容を注文として確定します。確定後は注文完了画面が表示されます。 |
| 店員呼び出し | 「注文」「お水」「片付け」「その他」の用件を選んでスタッフを呼び出せます。 |

### 管理者向け画面（Admin Panel）

| 機能 | 説明 |
| --- | --- |
| QR コード生成 | ベース URL とテーブル数（1〜100）を指定して、各テーブル用の QR コードを一括生成します。各 QR コードには `?table=<番号>` のパラメータが付与され、読み取るとそのテーブルとして注文画面が開きます。 |

## 画面遷移と URL

- **お客様画面**: `/`（デフォルト）
  - QR から開いた場合は URL に `?table=<番号>` が含まれており、スキャン画面をスキップして直接メニューが表示されます。
  - 直接アクセスした場合は QR スキャン画面が最初に表示されます。
- **管理画面**: `/admin` または `?admin=true`

## 利用フロー

1. 管理画面（`/admin`）で店舗のテーブル分の QR コードを生成し、印刷して各テーブルに設置します。
2. お客様がテーブルの QR コードをスマホで読み取ると、テーブル番号付きでメニュー画面が開きます。
3. メニューから商品を選んでカートに入れ、注文を確定します。
4. 必要に応じて「店員を呼ぶ」から用件を選択してスタッフを呼び出します。

## 技術スタック

- **フレームワーク**: [React 19](https://react.dev/)
- **言語**: TypeScript
- **ビルドツール**: [Vite 7](https://vite.dev/)
- **QR コード読み取り**: [html5-qrcode](https://github.com/mebjas/html5-qrcode)
- **QR コード生成**: [goqr.me API](https://goqr.me/api/)（`api.qrserver.com`）
- **状態管理**: React Context API（カート状態の共有）

## プロジェクト構成

```
src/
├── main.tsx                      # エントリーポイント
├── App.css                       # 全体スタイル
└── components/
    ├── AppRouter.tsx             # お客様画面／管理画面のルーティングとビュー切り替え
    ├── Header.tsx                # ヘッダー（ロゴ・テーブル番号・ナビゲーション）

    ├── MenuList.tsx              # メニュー一覧とカテゴリ絞り込み
    ├── CartContext.tsx           # カートの状態管理（Context）
    ├── Cart.tsx                  # カート表示と注文確定
    ├── OrderConfirmation.tsx     # 注文完了画面
    ├── StaffCall.tsx             # 店員呼び出し
    ├── AdminApp.tsx              # 管理画面のラッパー
    └── AdminPanel.tsx            # QR コード生成
```

## セットアップ

### 必要環境

- Node.js（推奨: 18 以上）

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

起動後、ブラウザで表示された URL にアクセスします。

> **補足**: QR コードの読み取りにはカメラへのアクセスが必要なため、HTTPS 環境（または `localhost`）での動作が前提となります。

### ビルド

```bash
npm run build
```

### プレビュー（ビルド結果の確認）

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

## 現状の制限事項

本リポジトリは現時点ではフロントエンドのみの実装です。バックエンドとの連携は未実装で、以下のように動作します。

- **メニュー**: `MenuList.tsx` 内にハードコードされたサンプルデータを表示します（居酒屋メニュー 10 品目）。
- **注文の送信**: 注文確定時、実際にはサーバーへ送信されず、注文内容はブラウザのコンソールに `console.log` で出力されます。
- **店員呼び出し**: 呼び出し内容も同様にコンソールに出力されるのみで、スタッフへの通知は行われません。
- **データの永続化**: カートや注文の状態はページをリロードすると失われます（永続化なし）。

実運用にあたっては、メニュー管理・注文受付・店員通知などを担うバックエンド API との接続が必要です。
